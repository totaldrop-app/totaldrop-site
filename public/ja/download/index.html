    ベータ

    Wayland 向けに Qt 6 で作られています。配色、フォント、アイコンはデスクトップ（Plasma、Hyprland、Omarchy、GNOME）から取り込みます。

    • ディストリビューションの系統ごとに別のパッケージ：すべて x86-64 用があり、Debian、Ubuntu、Fedora は ARM64 用もあります

新機能

Android 0.3.0-beta.7

  • ギャラリーやファイルなど、どのアプリからでも TotalDrop にファイルを共有できます。アプリアイコンを長押しすると、送信・受信・クリップボードを送信が表示されます。
  • テキストを送信：入力するか、他のアプリから共有するか、選択したテキストで「TotalDrop で送信」を選びます。届いたテキストは保存されずに表示され、コピーできます。
  • 確認用の単語の上の見出しが、幅の狭い画面に収まるようになりました。
  • 相手の端末が使わないリレーには接続しなくなりました。

Linux 0.3.0-beta.6

  • テキストの送信：送信画面の「テキストを送信」、またはアプリのランチャーメニューの「クリップボードを送信」。後者はクリップボードのテキストを入れた状態で送信画面を開きます。届いたテキストは保存されず表示され、隠れた文字は名前で示されます。「テキストをコピー」は届いたとおりにコピーします。コマンドラインでは totaldrop send --text "…"、標準入力のテキストには totaldrop send -。
  • ファイルマネージャーから送信：Dolphin、Nemo、ファイル（nautilus-python がある場合）の右クリックメニューに「TotalDrop で送信」。タスクバーやランチャーで TotalDrop を右クリックすると「ファイルを送信」「ファイルを受信」「クリップボードを送信」。これらのメニューは Flatpak にはありません。
  • Flatpak：x86-64 と ARM64 向け。システムを変更せずに、読み取り専用のシステムでもインストールでき、ネットワーク、~/Downloads/TotalDrop、選んだファイル、いくつかのデスクトップサービスにだけアクセスします。
  • どこでもあなたの言語：ソフトウェアセンターがアプリの全 35 言語で TotalDrop を紹介します。Qt 6.11 以降では、テキスト欄の右クリックメニューがアプリの言語になります。設定には、コードと確認用の単語は英語のままだと書かれています。
  • セキュリティ：受信側が別の中継サーバーを使うか使わない場合、送信側は自分の中継サーバーに接続しなくなりました。その中継サーバーは送信者の IP アドレスを見なくなります。コマンドラインは、エラー詳細の制御文字を端末に渡さず名前で示します（GHSA-c6jh-7p7q-8gg4）。

インストールするものを確認する

  • TotalDrop は Google Play、このページ、またはプロジェクトの GitHub リリースからのみ入手してください。それ以外の場所では公開していません。
  • Linux では、ダウンロードしたファイルを sudo pacman -U、sudo apt install ./ または sudo dnf install ./ のあとにファイル名を付けてインストールします。
  • Flatpak は sudo なしでインストールできます：flatpak install --user ./totaldrop-*.flatpak
  • GitHub の各リリースには SHA-256 チェックサムが記載されています。ファイルを実行する前に照合してください。
  • すべて公開されたソースコードからビルドされています。コードを読んで、自分でビルドすることもできます。
