TotalDrop のこれから

日付は目標であり、約束ではありません。機能は安全になって初めてリリースされます。すべての進捗は公開リポジトリで追えます。

完了

2026年10月

  • オープンなプロトコル

    TotalDrop Protocol v0：CPace による転送コード、耐量子 ML-KEM-768 を組み合わせた Noise XXpsk3、使い捨ての鍵による QUIC。誰でも互換アプリを作れるよう文書化しています。

    すべてのプラットフォーム

  • コマンドラインクライアント

    Linux、macOS、Windows のターミナルから送受信できます。

    Linux · macOS · Windows

  • Android ベータ版

    コードで送受信。あなたの言語で表示され、スマートフォンの配色に合わせて表示されます。Google Play で招待制。

    Android

  • Linux アプリ

    Qt 6 とネイティブ Wayland。KDE Plasma、Hyprland、Omarchy のテーマにリアルタイムで追従します。Arch、Debian、Ubuntu、Fedora 向けのパッケージ。

    Linux

  • ファイアウォール越しに

    両方のデバイスが待ち受けと発信を行うため、片側のファイアウォールで転送が止まることはなくなりました。

    すべてのプラットフォーム

  • インターネット越しに

    デバイスは STUN で自分のパブリックアドレスを調べ、ほとんどの家庭用ルーター越しに直接つながります。それができない場合、暗号化された通信は Cloudflare 上の私たちのリレーを経由します。リレーは中身を読めません。

    すべてのプラットフォーム

  • コマンドラインのプライバシーモード

    リレーのみ：相手にあなたの IP アドレスが知られることはありません。

    Linux · macOS · Windows

  • アプリのプライバシーモード

    設定のスイッチひとつで、すべてがリレーを経由し、相手のデバイスにあなたの IP アドレスが知られることはありません。

    Android · Linux

  • ARM 版 Linux

    Snapdragon X や NVIDIA RTX Spark などの ARM64 コンピューター向けの .deb と .rpm パッケージ。

    Linux

  • あなたの言語で

    アプリとこのサイトが35の言語に対応し、地域の数値形式に従います。下書きはネイティブスピーカーが確認中です。

    すべてのプラットフォーム

    リレー経由で始まった転送も、直接の経路が開いた時点でそちらに切り替わります。

    すべてのプラットフォーム

    Windows

    AUR ヘルパーでインストール・更新できます。

その後

2027年

  • iPhone、iPad、Mac

    寄付で Apple の開発者アカウントの費用がまかなえたら、ネイティブアプリを提供します。

    iOS · macOS

  • リンクとオフライン配信

    オンラインでない相手にも送れます。暗号化されたコピーが最大7日間待機し、リンクでのみ開けます。

    すべてのプラットフォーム

  • サーバーが一切保持しないアカウント

    任意：メールアドレス、電話番号、パスワード、入力する番号は不要です。アカウントはお使いのデバイスが保持し、自分のデバイス同士、そして保存した連絡先からあなたへ、コードなしで送れます。

    すべてのプラットフォーム

  • 保存済みの連絡先

    一度ペアリングして4つの単語を確認すれば、次からはその相手にコードなしで送れます。

    すべてのプラットフォーム

  • Tor 経由のプライバシーモード

    リレーへは Tor 経由で接続し、サイズもパディングで隠すため、私たちのサーバーでさえあなたの IP アドレスを見られません。

    すべてのプラットフォーム

監査の後

  • 独立したセキュリティ監査

    外部の企業がプロトコル、暗号、信頼できない入力を扱うコードをレビューします。報告書は全文を公開します。

    すべてのプラットフォーム

  • ハンドシェイクの形式モデル

    ハイブリッドハンドシェイクが約束どおりに機能することを、ProVerif または Tamarin で証明します。

    すべてのプラットフォーム

  • 耐量子署名

    デバイス鍵に Ed25519 と並べて ML-DSA-65 を追加し、将来の量子コンピューターでさえあなたになりすませないようにします。

    すべてのプラットフォーム

  • コミュニティのリレー

    希望する人は、署名付きのリストから、他の人が運営するリレーを使えます。
