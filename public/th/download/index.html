มีอะไรใหม่

Android 0.3.0-beta.7

  • แชร์ไฟล์ไปยัง TotalDrop จากแอปใดก็ได้ เช่น แกลเลอรีหรือไฟล์ กดไอคอนแอปค้างไว้เพื่อดู ส่ง รับ และส่งคลิปบอร์ด
  • ส่งข้อความ: พิมพ์เอง แชร์จากแอปอื่น หรือเลือก "ส่งด้วย TotalDrop" บนข้อความที่เลือก ข้อความที่ได้รับจะแสดงขึ้น ไม่ถูกบันทึก และคัดลอกได้
  • หัวข้อเหนือคำยืนยันแสดงได้พอดีบนหน้าจอแคบ
  • โทรศัพท์ไม่เชื่อมต่อกับรีเลย์ที่อีกอุปกรณ์จะไม่ใช้อีกต่อไป

Linux 0.3.0-beta.6

  • ส่งข้อความ: "ส่งข้อความ" ในหน้าจอส่ง หรือ "ส่งคลิปบอร์ด" ในเมนูตัวเปิดแอป ซึ่งเปิดหน้าจอส่งพร้อมข้อความจากคลิปบอร์ด ข้อความที่มาถึงจะแสดง ไม่ถูกบันทึก อักขระที่ซ่อนอยู่จะแสดงด้วยชื่อ และ "คัดลอกข้อความ" คัดลอกตามที่มาถึงทุกประการ ในบรรทัดคำสั่ง: totaldrop send --text "…" หรือ totaldrop send - สำหรับข้อความจากอินพุตมาตรฐาน
  • ส่งจากตัวจัดการไฟล์: "ส่งด้วย TotalDrop" ในเมนูคลิกขวาของ Dolphin, Nemo และ Files (เมื่อติดตั้ง nautilus-python) คลิกขวาที่ TotalDrop ในแถบงานหรือตัวเปิดแอปจะมี "ส่งไฟล์" "รับไฟล์" และ "ส่งคลิปบอร์ด" เมนูเหล่านี้ไม่มีใน Flatpak
  • Flatpak: สำหรับ x86-64 และ ARM64 ติดตั้งได้โดยไม่แตะระบบ แม้ระบบจะเป็นแบบอ่านอย่างเดียว และเข้าถึงได้เฉพาะเครือข่าย ~/Downloads/TotalDrop ไฟล์ที่คุณเลือก และบริการเดสก์ท็อปบางอย่าง
  • ภาษาของคุณทุกที่: ศูนย์ซอฟต์แวร์อธิบาย TotalDrop ได้ครบทั้ง 35 ภาษาของแอป ตั้งแต่ Qt 6.11 เมนูคลิกขวาของช่องข้อความเป็นภาษาของแอป การตั้งค่าบอกว่ารหัสและคำยืนยันยังคงเป็นภาษาอังกฤษ
  • ความปลอดภัย: อุปกรณ์ที่ส่งจะไม่เชื่อมต่อรีเลย์ของตนอีกต่อไปเมื่ออุปกรณ์ที่รับใช้รีเลย์อื่นหรือไม่ใช้เลย รีเลย์นั้นจึงไม่เห็นที่อยู่ IP ของผู้ส่ง บรรทัดคำสั่งแสดงอักขระควบคุมในรายละเอียดข้อผิดพลาดด้วยชื่อ แทนที่จะส่งต่อให้เทอร์มินัล (GHSA-c6jh-7p7q-8gg4)

ตรวจสอบสิ่งที่คุณติดตั้ง

  • ดาวน์โหลด TotalDrop จาก Google Play, หน้านี้ หรือ GitHub releases ของโปรเจกต์เท่านั้น เราไม่ได้เผยแพร่ที่อื่น
  • บน Linux ให้ติดตั้งไฟล์ที่ดาวน์โหลดมาด้วย sudo pacman -U, sudo apt install ./ หรือ sudo dnf install ./ ตามด้วยชื่อไฟล์
  • Flatpak ติดตั้งได้โดยไม่ต้องใช้ sudo: flatpak install --user ./totaldrop-*.flatpak
  • ทุกรุ่นบน GitHub มีค่า checksum แบบ SHA-256 เปรียบเทียบก่อนเรียกใช้ไฟล์
  • ทุกอย่างสร้างจากซอร์สโค้ดสาธารณะ ซึ่งคุณอ่านและบิลด์เองได้
