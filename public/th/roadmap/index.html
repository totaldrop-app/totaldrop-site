ตุลาคม 2026

  • โปรโตคอลแบบเปิด

    TotalDrop Protocol v0: รหัสการโอนด้วย CPace, Noise XXpsk3 กับ ML-KEM-768 แบบหลังควอนตัม, QUIC กับคีย์แบบใช้ครั้งเดียว เขียนไว้เป็นเอกสารเพื่อให้ใครก็สร้างแอปที่ใช้ร่วมกันได้

    ทุกแพลตฟอร์ม

  • ไคลเอนต์บรรทัดคำสั่ง

    ส่งและรับจากเทอร์มินัลบน Linux, macOS และ Windows

    Linux · macOS · Windows

  • Android เบต้า

    ส่งและรับด้วยรหัส ในภาษาของคุณ ใช้สีตามโทรศัพท์ บน Google Play ด้วยคำเชิญ

    Android

  • แอป Linux

    Qt 6 และ Wayland แบบเนทีฟ ตามธีมของ KDE Plasma, Hyprland และ Omarchy แบบสด มีแพ็กเกจสำหรับ Arch, Debian, Ubuntu และ Fedora

    Linux

  • ผ่านไฟร์วอลล์

    อุปกรณ์ทั้งสองทั้งรอรับและติดต่อออก ไฟร์วอลล์ฝั่งเดียวจึงไม่หยุดการโอนอีกต่อไป

    ทุกแพลตฟอร์ม

  • ข้ามอินเทอร์เน็ต

    อุปกรณ์หาที่อยู่สาธารณะของตนด้วย STUN และเชื่อมต่อกันโดยตรงผ่านเราเตอร์บ้านส่วนใหญ่ได้ เมื่อทำไม่ได้ ทราฟฟิกที่เข้ารหัสจะผ่านรีเลย์ของเราบน Cloudflare ซึ่งอ่านข้อมูลนั้นไม่ได้

    ทุกแพลตฟอร์ม

  • โหมดความเป็นส่วนตัวในบรรทัดคำสั่ง

    ใช้รีเลย์เท่านั้น: อีกฝ่ายจะไม่มีทางรู้ที่อยู่ IP ของคุณ

    Linux · macOS · Windows

  • โหมดความเป็นส่วนตัวในแอป

    สวิตช์เดียวในการตั้งค่า: ทุกอย่างผ่านรีเลย์ อุปกรณ์อีกเครื่องจึงไม่มีทางรู้ที่อยู่ IP ของคุณ

    Android · Linux

  • Linux บน ARM

    แพ็กเกจ .deb และ .rpm สำหรับคอมพิวเตอร์ ARM64 เช่น Snapdragon X และ NVIDIA RTX Spark

    Linux

  • ในภาษาของคุณ

    แอปและเว็บไซต์นี้ใน 35 ภาษา พร้อมรูปแบบตัวเลขตามภูมิภาคของคุณ เจ้าของภาษากำลังตรวจทานฉบับร่าง

    ทุกแพลตฟอร์ม

    การโอนที่เริ่มผ่านรีเลย์จะย้ายไปใช้เส้นทางตรงทันทีที่เปิดได้

2027

  • iPhone, iPad และ Mac

    แอปเนทีฟ เมื่อเงินบริจาคครอบคลุมบัญชีนักพัฒนาของ Apple

    iOS · macOS

  • ลิงก์และการส่งแบบออฟไลน์

    ส่งให้คนที่ไม่ได้ออนไลน์: สำเนาที่เข้ารหัสจะรออยู่ได้นานสูงสุด 7 วัน และเปิดได้ด้วยลิงก์เท่านั้น

    ทุกแพลตฟอร์ม

  • บัญชีที่เซิร์ฟเวอร์ไม่เคยเก็บ

    ไม่บังคับ: ไม่ต้องมีอีเมล โทรศัพท์ รหัสผ่าน หรือตัวเลขให้พิมพ์ อุปกรณ์ของคุณเป็นผู้เก็บบัญชี อุปกรณ์ของคุณส่งถึงกันเอง และผู้ติดต่อที่บันทึกไว้ส่งถึงคุณได้โดยไม่ต้องใช้รหัส

    ทุกแพลตฟอร์ม

  • รายชื่อติดต่อที่บันทึกไว้

    จับคู่ครั้งเดียว ตรวจสอบสี่คำ แล้วส่งถึงคนนั้นได้อีกโดยไม่ต้องใช้รหัส

    ทุกแพลตฟอร์ม

  • โหมดความเป็นส่วนตัวผ่าน Tor

    เข้าถึงรีเลย์ผ่าน Tor พร้อมเติมขนาดข้อมูล แม้แต่เซิร์ฟเวอร์ของเราก็ไม่เห็นที่อยู่ IP ของคุณ

    ทุกแพลตฟอร์ม

  • การตรวจสอบความปลอดภัยโดยอิสระ
