ตรวจงานอย่างไร

  1. การเปลี่ยนแปลงทั่วไปเริ่มจาก issue สาธารณะ และเข้าสู่แอปได้ผ่าน pull request เท่านั้น

  2. ทุก pull request ต้องผ่านการตรวจอัตโนมัติและการตรวจทานโดยคนหรือเอเจนต์ AI ที่ไม่ได้เขียนมัน

  3. ผู้ดูแลโครงการรวมการเปลี่ยนแปลงที่ตรวจทานแล้ว และมีเพียงหัวหน้าโครงการเท่านั้นที่อนุมัติการเผยแพร่และการติดตั้งใช้งาน รุ่นเผยแพร่สร้างใน GitHub Actions ไม่เคยสร้างบนคอมพิวเตอร์ส่วนตัว
