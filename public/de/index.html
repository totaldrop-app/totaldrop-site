Senden Sie Dateien und Text direkt an ein anderes Gerät.

TotalDrop überträgt Dateien, ganze Ordner und Text aus der Zwischenablage direkt von Ihrem Gerät auf das andere, Ende-zu-Ende-verschlüsselt mit Post-Quanten-Schlüsseln. Teilen Sie einen kurzen Code; niemand dazwischen kann lesen, was Sie senden. Kein Konto, keine E-Mail, keine Telefonnummer.

Warum TotalDrop

  • Nichts wird hochgeladen

    Dateien gehen von Ihrem Gerät auf das der anderen Person. Keine Kopie wartet auf dem Server einer Firma, und kein Link läuft nach einer Woche ab.

  • Niemals ein Konto

    Keine E-Mail, keine Telefonnummer, keine Registrierung. Ein kurzer Code ist alles, was zwei Geräte brauchen.

  • Jede Plattform, eine App

    Heute Android, Linux und die Kommandozeile; Windows, macOS und iOS sind in Arbeit. Vom Telefon zum Laptop, von jeder Marke zu jeder Marke.

  • Dateien, Ordner und Zwischenablage-Text

    Senden Sie Fotos in Originalqualität, riesige Ordner oder eine kopierte Notiz. Text kommt kopierfertig an, versteckte Zeichen werden benannt, nichts wird auf die Festplatte geschrieben.

  • Geprüft statt vertraut

    Vier Wörter auf beiden Bildschirmen beweisen, dass niemand dazwischensteht. Die Verschlüsselung ist Ende-zu-Ende und post-quantensicher.

  • Frei und offen, für immer

    Quelloffen unter der GPL, finanziert durch Spenden. Keine Werbung, kein Tracking, kein Premium-Tarif.

Drei Schritte

  1. Dateien oder Text auswählen

    Wählen Sie Dateien, ganze Ordner oder Text aus der Zwischenablage – oder senden Sie direkt über das Teilen-Menü des Systems oder den Dateimanager.

  2. Code teilen

    Eine Zahl und zwei Wörter, etwa 7-harbor-rocket. Er funktioniert einmal und verfällt dann.

  3. Vier Wörter vergleichen

    Beide Bildschirme zeigen dieselben vier Wörter. Stimmen sie überein, gehört die Verbindung nur Ihnen.

Über das Internet verbinden sich die beiden Geräte direkt, wo immer es geht. Steht ein Router oder eine Firewall im Weg, läuft die verschlüsselte Übertragung über unseren Relay-Server, der sie nicht lesen kann.

Kryptografie und formale Verifikation

Nur Sie und der Empfänger können es öffnen

Verschlüsselt, bevor es losgeht
Dateien werden auf Ihrem Gerät verschlüsselt und erst auf dem des Empfängers entschlüsselt. Die Schlüssel existieren nirgendwo sonst.
Post-Quanten-PAKE-Handshake
Der Code steuert einen CPace-Handshake, der Noise XXpsk3 mit hybriden X25519- und ML-KEM-768-Schlüsseln speist. Ein falscher Versuch scheitert sofort und verbraucht den Code.
Unser Server stellt nur vor
Er sieht Ihre IP-Adresse und die Nummer des Codes, nie die Wörter, die Dateinamen oder die Dateien. Bei aktiviertem Privatsphäre-Modus erfährt selbst das andere Gerät Ihre IP-Adresse nie.
Mit Tamarin bewiesen, vor 1.0 auditiert
Sechs symbolische Modelle, 61 maschinell geprüfte Lemmata und 27 Regressionsmutanten verifizieren das kommende serverblinde Ghost-Ring-Konto im Beweiser Tamarin. Version 1.0 wartet auf ein unabhängiges Audit.
