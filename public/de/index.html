Senden Sie eine Datei direkt an ein anderes Gerät.

TotalDrop überträgt Dateien direkt von Ihrem Gerät auf das der anderen Person, Ende-zu-Ende-verschlüsselt. Sie teilen einen kurzen Code; niemand dazwischen kann lesen, was Sie senden. Kein Konto, keine E-Mail, keine Telefonnummer.

Warum TotalDrop

  • Nichts wird hochgeladen

    Dateien gehen von Ihrem Gerät auf das der anderen Person. Keine Kopie wartet auf dem Server einer Firma, und kein Link läuft nach einer Woche ab.

  • Niemals ein Konto

    Keine E-Mail, keine Telefonnummer, keine Registrierung. Ein kurzer Code ist alles, was zwei Geräte brauchen.

  • Jede Plattform, eine App

    Heute Android, Linux und die Kommandozeile; Windows, macOS und iOS sind in Arbeit. Vom Telefon zum Laptop, von jeder Marke zu jeder Marke.

  • Keine Größenbeschränkung von uns

    Ganze Ordner, lange Videos, Fotos in Originalqualität. Die Grenze setzen nur Ihr Speicher und Ihre Verbindung.

  • Geprüft statt vertraut

    Vier Wörter auf beiden Bildschirmen beweisen, dass niemand dazwischensteht. Die Verschlüsselung ist Ende-zu-Ende und post-quantensicher.

  • Frei und offen, für immer

    Quelloffen unter der GPL, finanziert durch Spenden. Keine Werbung, kein Tracking, kein Premium-Tarif.

Drei Schritte

  1. Dateien auswählen

    Jeder Dateityp, so viele Sie möchten. Der Empfänger erhält nur, was Sie ausgewählt haben.

  2. Code teilen

    Eine Zahl und zwei Wörter, etwa 7-harbor-rocket. Er funktioniert einmal und verfällt dann.

  3. Vier Wörter vergleichen

    Beide Bildschirme zeigen dieselben vier Wörter. Stimmen sie überein, gehört die Verbindung nur Ihnen.

Über das Internet verbinden sich die beiden Geräte direkt, wo immer es geht. Steht ein Router oder eine Firewall im Weg, läuft die verschlüsselte Übertragung über unseren Relay-Server, der sie nicht lesen kann.

Nur Sie und der Empfänger können es öffnen

Verschlüsselt, bevor es losgeht
Dateien werden auf Ihrem Gerät verschlüsselt und erst auf dem des Empfängers entschlüsselt. Die Schlüssel existieren nirgendwo sonst.
Der Code lässt sich nicht offline erraten
Der Code wird durch einen PAKE-Handshake zu einem Schlüssel, sodass ein falscher Versuch sofort scheitert und verbraucht ist. Der Schlüsselaustausch enthält Post-Quanten-ML-KEM.
Unser Server stellt nur vor
Er sieht Ihre IP-Adresse und die Zahl des Codes, nie die Wörter, die Dateinamen oder die Dateien. Er speichert keine Protokolle.
