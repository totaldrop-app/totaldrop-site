    Beta

    Mit Qt 6 für Wayland gebaut. Übernimmt Farben, Schriften und Symbole von Ihrem Desktop: Plasma, Hyprland, Omarchy, GNOME.

Neuigkeiten

Android 0.3.0-beta.7

  • Teilen Sie Dateien aus jeder App mit TotalDrop, etwa aus Galerie oder Dateien. Langes Drücken auf das App-Symbol bietet Senden, Empfangen und Zwischenablage senden.
  • Senden Sie einen Text: tippen, aus einer anderen App teilen oder bei markiertem Text „Mit TotalDrop senden“ wählen. Ein empfangener Text wird angezeigt, nicht gespeichert, und lässt sich kopieren.
  • Die Überschrift über den Prüfwörtern passt auf schmale Bildschirme.
  • Ihr Telefon verbindet sich nicht mehr mit einem Relay, das das andere Gerät nicht nutzt.

Linux 0.3.0-beta.6

  • Text senden: „Text senden“ im Sendebildschirm oder „Zwischenablage senden“ im Startmenü der App, das den Sendebildschirm mit dem Text der Zwischenablage öffnet. Ein ankommender Text wird angezeigt, nicht gespeichert; versteckte Zeichen werden benannt, und „Text kopieren“ kopiert ihn genau so, wie er kam. Auf der Kommandozeile: totaldrop send --text "…" oder totaldrop send - für Text aus der Standardeingabe.
  • Aus dem Dateimanager senden: „Mit TotalDrop senden“ im Kontextmenü von Dolphin, Nemo und Dateien (mit nautilus-python). Ein Rechtsklick auf TotalDrop in der Taskleiste oder im Starter bietet „Dateien senden“, „Dateien empfangen“ und „Zwischenablage senden“. Die Dateimanager-Menüs gibt es im Flatpak nicht.
  • Flatpak: für x86-64 und ARM64; es installiert sich, ohne das System zu verändern, auch auf schreibgeschützten Systemen, und erreicht nur das Netz, ~/Downloads/TotalDrop, die gewählten Dateien und einige Desktop-Dienste.
  • Überall Ihre Sprache: Softwarezentren beschreiben TotalDrop in allen 35 Sprachen der App. Ab Qt 6.11 ist das Kontextmenü von Textfeldern in der Sprache der App. Die Einstellungen sagen, dass Codes und Prüfwörter Englisch bleiben.
  • Sicherheit: Ein sendendes Gerät verbindet sich nicht mehr mit seinem Relay, wenn das empfangende Gerät ein anderes oder keines nutzt; dieses Relay sieht die IP-Adresse des Senders nicht mehr. Die Kommandozeile benennt Steuerzeichen in Fehlerdetails, statt sie an das Terminal weiterzugeben (GHSA-c6jh-7p7q-8gg4).

Prüfen Sie, was Sie installieren

  • Laden Sie TotalDrop nur über Google Play, diese Seite oder die GitHub-Releases des Projekts herunter. Wir veröffentlichen nirgendwo sonst.
  • Unter Linux installieren Sie die heruntergeladene Datei mit sudo pacman -U, sudo apt install ./ oder sudo dnf install ./ und ihrem Namen.
  • Ein Flatpak installieren Sie ohne sudo: flatpak install --user ./totaldrop-*.flatpak
  • Jede Version auf GitHub listet SHA-256-Prüfsummen auf. Vergleichen Sie sie, bevor Sie eine Datei ausführen.
  • Alles wird aus dem öffentlichen Quellcode gebaut, den Sie lesen und selbst bauen können.
