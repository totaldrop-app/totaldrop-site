Що чекає на TotalDrop

Терміни — це цілі, а не обіцянки: функція виходить, лише коли вона безпечна. Кожен крок можна відстежувати у відкритому репозиторії.

Готово

Жовтень 2026

  • Відкритий протокол

    TotalDrop Protocol v0: коди передачі на CPace, Noise XXpsk3 з постквантовим ML-KEM-768, QUIC з одноразовими ключами. Описаний, щоб будь-хто міг створити сумісний застосунок.

    Усі платформи

  • Клієнт командного рядка

    Надсилання й отримання з термінала в Linux, macOS і Windows.

    Linux · macOS · Windows

  • Бета для Android

    Надсилання й отримання за кодом, вашою мовою, у кольорах телефона. У Google Play за запрошеннями.

    Android

  • Застосунок для Linux

    Qt 6 і нативний Wayland. На льоту слідує темі KDE Plasma, Hyprland і Omarchy. Пакети для Arch, Debian, Ubuntu і Fedora.

    Linux

  • Крізь брандмауери

    Обидва пристрої і слухають, і підключаються самі, тож брандмауер на одному боці більше не зупиняє передачу.

    Усі платформи

  • Через інтернет

    Пристрої дізнаються свою публічну адресу через STUN і з'єднуються напряму через більшість домашніх роутерів. Коли це неможливо, зашифрований трафік іде через наш ретранслятор у Cloudflare, який не може його прочитати.

    Усі платформи

  • Режим конфіденційності в командному рядку

    Лише через ретранслятор: інша сторона ніколи не дізнається вашої IP-адреси.

    Linux · macOS · Windows

  • Режим конфіденційності в застосунках

    Один перемикач у налаштуваннях: усе йде через ретранслятор, тож інший пристрій ніколи не дізнається вашої IP-адреси.

    Android · Linux

  • Linux на ARM

    Пакети .deb і .rpm для комп'ютерів на ARM64, як-от Snapdragon X і NVIDIA RTX Spark.

    Linux

  • Вашою мовою

    Застосунки й цей сайт 35 мовами, з числовими форматами вашого регіону. Носії мови перевіряють чернетки.

Зима 2026–27

  • Відновлення перерваних передач

    Обірване з'єднання продовжує з місця зупинки, не надсилаючи знову те, що вже надійшло.

    Усі платформи

  • Перехід з ретранслятора на пряме з'єднання

    Передача, що почалася через ретранслятор, переходить на прямий шлях, щойно він з'являється.

    Усі платформи

  • Застосунок для Windows

    Нативний застосунок для Windows 11. З підписом, коли пожертви покриють сертифікат.

  • Arch User Repository

    Установлення й оновлення через ваш AUR-помічник.

Пізніше

2027

  • iPhone, iPad і Mac

    Нативні застосунки, коли пожертви покриють обліковий запис розробника Apple.

    iOS · macOS

  • Посилання й доставка офлайн

    Надсилання тому, хто не в мережі: зашифрована копія чекає до 7 днів, і відкрити її можна лише за посиланням.

    Усі платформи

  • Обліковий запис, який сервер ніколи не зберігає

    Необов'язково: без пошти, телефону, пароля чи номера для введення. Обліковий запис зберігають ваші пристрої; ваші пристрої надсилають файли одне одному, а збережені контакти — вам, без коду.

    Усі платформи

  • Збережені контакти

    Поєднайтеся один раз, звірте чотири слова й надсилайте цій людині файли без коду.

    Усі платформи

  • Режим конфіденційності через Tor

    Доступ до ретранслятора через Tor з вирівнюванням розмірів, щоб навіть наші сервери не бачили вашої IP-адреси.

    Усі платформи
Версія 1.0

Після аудиту

  • Незалежний аудит безпеки

    Стороння компанія перевіряє протокол, криптографію і код, що обробляє недовірені дані. Повний звіт публікується.

    Усі платформи

  • Формальна модель рукостискання

    Доведення в ProVerif або Tamarin того, що гібридне рукостискання виконує свої обіцянки.

    Усі платформи

  • Постквантові підписи

    До ключів пристроїв поруч з Ed25519 додається ML-DSA-65, щоб навіть майбутній квантовий комп'ютер не зміг видати себе за вас.

    Усі платформи

  • Ретранслятори спільноти

    Охочі зможуть користуватися ретрансляторами, які утримують інші люди, з підписаного списку.
