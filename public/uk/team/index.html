Як перевіряють роботу

  1. Повсякденні зміни починаються з відкритої задачі й потрапляють у застосунок лише через pull request.

  2. Кожен pull request проходить автоматичні перевірки та перевірку людиною або ШІ-агентом, який його не писав.

  3. Зливає, випускає й розгортає лише керівник проєкту. Випуски збираються в GitHub Actions, ніколи на особистому комп'ютері.
