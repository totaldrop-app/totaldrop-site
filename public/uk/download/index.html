Завантажити TotalDrop

Безкоштовно, з відкритим кодом, без облікового запису. Виберіть пристрій; той, яким ви користуєтеся зараз, позначено.

    Командний рядок

    Доступно

    Сьогодні вже зібрано в пакетах для Linux або збирається з вихідного коду через Cargo. Надсилає файли, цілі папки й текст із аргументів або стандартного введення.

    cargo install --locked \
  --git https://github.com/totaldrop-app/totaldrop \
  totaldrop-cli
    totaldrop send ~/Photos/trip
totaldrop send --text "hello"
totaldrop receive 7-harbor-rocket
  • Для цього пристрою

    Застосунок для Linux

    Бета

    Створено на Qt 6 для Wayland. Бере кольори, шрифти й значки з вашої стільниці: Plasma, Hyprland, Omarchy, GNOME.

    • Окремий пакет для кожної родини дистрибутивів: усі для x86-64; Debian, Ubuntu і Fedora також для ARM64
    • Пакети .pkg, .deb і .rpm також установлюють команду totaldrop і контекстні меню для Dolphin, Файлів і Nemo
    • Використовуйте одночасно лише один пакет для Linux. Flatpak і пакет .pkg, .deb чи .rpm мають спільне ім'я, тож поки один відкритий, запуск іншого виводить відкрите вікно на передній план, а не відкриває друге.
    Arch, Omarchy, Manjaro Debian, Ubuntu (.deb) Fedora (.rpm) Flatpak

    Кнопки вище — для x86-64. Для ARM64: Debian, Ubuntu (.deb, ARM64) · Fedora (.rpm, ARM64) · Flatpak (ARM64)

Що нового

Android 0.3.0-beta.7

  • Діліться файлами з TotalDrop з будь-якого застосунку, наприклад з Галереї чи Файлів. Довге натискання на значок відкриває «Надіслати», «Отримати» й «Надіслати буфер обміну».
  • Надішліть текст: введіть, поділіться з іншого застосунку або виберіть «Надіслати через TotalDrop» для виділеного тексту. Отриманий текст показується, не зберігається, і його можна скопіювати.
  • Заголовок над словами перевірки вміщується на вузьких екранах.
  • Телефон більше не підключається до ретранслятора, яким не користуватиметься інший пристрій.

Linux 0.3.0-beta.6

  • Надсилання тексту: «Надіслати текст» на екрані надсилання або «Надіслати буфер обміну» в меню запуску застосунку, яке відкриває екран надсилання з текстом із буфера обміну. Отриманий текст показується, а не зберігається; приховані символи показано за назвою, а «Копіювати текст» копіює його точно таким, яким він надійшов. У командному рядку: totaldrop send --text "…" або totaldrop send - для тексту зі стандартного введення.
  • Надсилання з файлового менеджера: «Надіслати через TotalDrop» у контекстному меню Dolphin, Nemo і Файлів (з nautilus-python). Клацання правою кнопкою на TotalDrop на панелі завдань або в меню запуску дає «Надсилання файлів», «Отримання файлів» і «Надіслати буфер обміну». Цих меню немає у Flatpak.
  • Flatpak: для x86-64 і ARM64; встановлюється, не змінюючи систему, зокрема там, де система лише для читання, і має доступ тільки до мережі, ~/Downloads/TotalDrop, вибраних файлів і кількох служб стільниці.
  • Ваша мова всюди: центри програм описують TotalDrop усіма 35 мовами застосунку. З Qt 6.11 і новіше контекстне меню текстових полів мовою застосунку. Налаштування повідомляють, що коди й слова перевірки лишаються англійською.
  • Безпека: пристрій, що надсилає, більше не під’єднується до свого ретранслятора, якщо пристрій, що отримує, використовує інший або жодного; цей ретранслятор більше не бачить IP-адресу відправника. Командний рядок показує керівні символи в подробицях помилки за назвою, а не передає їх терміналу (GHSA-c6jh-7p7q-8gg4).

Перевіряйте, що встановлюєте

  • Завантажуйте TotalDrop лише з Google Play, з цієї сторінки або з випусків проєкту на GitHub. Більше ніде ми не публікуємо.
  • У Linux установіть завантажений файл командою sudo pacman -U, sudo apt install ./ або sudo dnf install ./ з його назвою.
  • Flatpak встановлюється без sudo: flatpak install --user ./totaldrop-*.flatpak
  • Для кожного випуску на GitHub наведено контрольні суми SHA-256. Звірте їх, перш ніж запускати файл.
  • Усе збирається з відкритого вихідного коду, який ви можете прочитати й зібрати самі.
