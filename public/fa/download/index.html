    cargo install --locked \
  --git https://github.com/totaldrop-app/totaldrop \
  totaldrop-cli

totaldrop send --text "hello"
totaldrop receive 7-harbor-rocket

    برنامه Linux

    بتا

    ساخته‌شده با Qt 6 برای Wayland. رنگها، قلم‌ها و نمادهایش را از دسکتاپ شما می‌گیرد: Plasma، Hyprland، Omarchy، GNOME.

    • یک بسته جداگانه برای هر خانواده از توزیع‌ها: همه برای x86-64؛ Debian، Ubuntu و Fedora برای ARM64 هم
    • بسته‌های .pkg و .deb و .rpm فرمان totaldrop و منوهای کلیک راست برای Dolphin، Files و Nemo را هم نصب می‌کنند
    • هر بار فقط از یک بسته Linux استفاده کنید. Flatpak و بسته .pkg، .deb یا .rpm یک نام مشترک دارند، پس وقتی یکی باز است، اجرای دیگری به‌جای باز کردن پنجره دوم، پنجره باز را جلو می‌آورد.
    Arch, Omarchy, Manjaro Debian, Ubuntu (.deb) Fedora (.rpm) Flatpak

    دکمه‌های بالا برای x86-64 هستند. برای ARM64: Debian, Ubuntu (.deb, ARM64) · Fedora (.rpm, ARM64) · Flatpak (ARM64)

تازه‌ها

Android 0.3.0-beta.7

  • از هر برنامه‌ای، مثل گالری یا فایل‌ها، فایل‌ها را با TotalDrop هم‌رسانی کنید. با نگه‌داشتن نماد برنامه، ارسال، دریافت و ارسال محتوای کلیپ‌بورد نمایش داده می‌شود.
  • متن بفرستید: آن را بنویسید، از برنامه‌ای دیگر هم‌رسانی کنید یا روی متن انتخاب‌شده «ارسال با TotalDrop» را بزنید. متن رسیده نمایش داده می‌شود، ذخیره نمی‌شود و می‌توان آن را کپی کرد.
  • عنوان بالای کلمات تأیید در صفحه‌های باریک جا می‌شود.
  • تلفن شما دیگر به رله‌ای که دستگاه دیگر از آن استفاده نمی‌کند وصل نمی‌شود.

Linux 0.3.0-beta.6

  • ارسال متن: «ارسال متن» در صفحهٔ ارسال، یا «ارسال محتوای کلیپ‌بورد» در منوی اجراکنندهٔ برنامه، که صفحهٔ ارسال را با متن کلیپ‌بورد باز می‌کند. متنی که می‌رسد نمایش داده می‌شود، ذخیره نمی‌شود؛ نویسه‌های پنهان با نامشان دیده می‌شوند و «کپی متن» آن را دقیقاً همان‌طور که رسیده کپی می‌کند. در خط فرمان: totaldrop send --text "…"، یا totaldrop send - برای متن ورودی استاندارد.
  • ارسال از مدیر فایل: «ارسال با TotalDrop» در منوی کلیک راست Dolphin، Nemo و Files (با nautilus-python). کلیک راست روی TotalDrop در نوار وظیفه یا اجراکننده گزینه‌های «ارسال فایل»، «دریافت فایل» و «ارسال محتوای کلیپ‌بورد» را نشان می‌دهد. این منوها در Flatpak نیستند.
  • Flatpak: برای x86-64 و ARM64؛ بدون دست زدن به سیستم نصب می‌شود، حتی جایی که سیستم فقط‌خواندنی است، و فقط به شبکه، ~/Downloads/TotalDrop، فایل‌هایی که انتخاب می‌کنید و چند سرویس میزکار دسترسی دارد.
  • زبان شما همه‌جا: مراکز نرم‌افزار TotalDrop را به هر ۳۵ زبان برنامه معرفی می‌کنند. با Qt 6.11 یا جدیدتر، منوی کلیک راست کادرهای متن به زبان برنامه است. تنظیمات می‌گوید کدها و واژه‌های تأیید انگلیسی می‌مانند.
  • امنیت: دستگاه فرستنده دیگر به رلهٔ خودش وصل نمی‌شود وقتی دستگاه گیرنده رلهٔ دیگری به کار می‌برد یا هیچ رله‌ای ندارد؛ آن رله دیگر نشانی IP فرستنده را نمی‌بیند. خط فرمان نویسه‌های کنترلی در جزئیات خطا را به‌جای فرستادن به پایانه با نامشان نشان می‌دهد (GHSA-c6jh-7p7q-8gg4).

آنچه نصب می‌کنید را بررسی کنید

  • TotalDrop را فقط از Google Play، از همین صفحه یا از انتشارهای پروژه در GitHub بگیرید. ما در هیچ جای دیگری منتشر نمی‌کنیم.
  • در Linux، فایلی را که دانلود کرده‌اید با sudo pacman -U، sudo apt install ./ یا sudo dnf install ./ و نام آن نصب کنید.
  • Flatpak بدون sudo نصب می‌شود: flatpak install --user ./totaldrop-*.flatpak
  • هر انتشار در GitHub چک‌سام‌های SHA-256 را فهرست می‌کند. پیش از اجرای یک فایل آن‌ها را مقایسه کنید.
  • همه چیز از کد منبع عمومی ساخته می‌شود که می‌توانید آن را بخوانید و خودتان بسازید.
