TotalDrop 即將推出的功能

日期是目標，不是承諾：功能只有在安全時才會推出。每一步都可以在公開的儲存庫中追蹤。

已完成

2026年10月

  • 開放協定

    TotalDrop Protocol v0：以 CPace 為基礎的傳輸代碼、結合後量子 ML-KEM-768 的 Noise XXpsk3，以及使用一次性金鑰的 QUIC。已寫成文件，任何人都能開發相容的應用程式。

    所有平台

  • 命令列用戶端

    在 Linux 終端機中傳送和接收，或透過 Cargo 從原始碼建置（計畫提供 macOS 和 Windows 預先編譯執行檔）。

    Linux

  • Android 測試版

    用代碼傳送和接收，使用你的語言，跟隨手機的配色。在 Google Play 上透過邀請提供。

    Android

  • Linux 應用程式

    Qt 6 與原生 Wayland。即時跟隨 KDE Plasma、Hyprland 和 Omarchy 的主題。提供 Arch、Debian、Ubuntu 和 Fedora 套件。

    Linux

  • 穿越防火牆

    兩部裝置都會監聽並主動連線，因此一方的防火牆不會再擋下傳輸。

    所有平台

  • 透過網際網路

    裝置透過 STUN 得知自己的公開位址，並能穿過大多數家用路由器直接連線。無法直接連線時，加密流量會經過我們架設在 Cloudflare 上的中繼伺服器，中繼伺服器無法讀取內容。

    所有平台

  • 命令列中的隱私模式

    僅使用中繼：對方永遠不會知道你的 IP 位址。

    Linux

  • App 中的隱私模式

    設定中的一個開關：所有內容都經由中繼伺服器，對方裝置永遠不會知道你的 IP 位址。

    Android · Linux

  • ARM 上的 Linux

    適用於 Snapdragon X 和 NVIDIA RTX Spark 等 ARM64 電腦的 .deb 和 .rpm 套件。

    Linux

  • 使用你的語言

    應用程式和本網站支援 35 種語言，並使用你所在地區的數字格式。母語人士正在檢查草稿。

    所有平台
現在

2026年11月

  • 用相機掃描 QR 碼

    不必輸入代碼，把手機對準傳送者的螢幕就行。

    Android

  • 在瀏覽器中接收

    開啟連結，輸入代碼，儲存檔案。不需安裝，依然端對端加密。

    Web
接下來

2026–27 年冬季

  • 繼續中斷的傳輸

    連線中斷後會從中斷處繼續，不會重新傳送已經收到的部分。

    所有平台

  • 從中繼切換為直接連線

    經由中繼開始的傳輸，一旦有直接路徑可用，就會立即切換過去。

    所有平台

  • Windows 應用程式

    原生 Windows 11 應用程式。等捐款足以支付憑證後進行簽署。

    Windows

  • Arch User Repository

    用你的 AUR 輔助工具安裝和更新。

    Linux
之後

2027年

  • iPhone、iPad 和 Mac

    等捐款足以支付 Apple 開發者帳號後推出原生 App。

    iOS · macOS

  • 連結與離線送達

    傳送給不在線上的人：加密副本最多等待 7 天，只有連結能開啟它。

    所有平台

  • 伺服器從不保存的帳號

    選用：不需電子郵件、手機號碼、密碼，也不需輸入任何號碼。帳號由你的裝置保存；你自己的裝置之間，以及已儲存的聯絡人向你，都不需代碼即可傳送。

    所有平台

  • 已儲存的聯絡人

    配對一次，核對四個單字，之後再傳送給這個人就不需要代碼。

    所有平台

  • 透過 Tor 的隱私模式

    透過 Tor 連線到中繼伺服器，並對大小進行填充，連我們的伺服器也看不到你的 IP 位址。

    所有平台
1.0 版

稽核之後

  • 獨立安全稽核

    由外部公司審查協定、密碼學實作以及處理不可信輸入的程式碼。完整報告將會公開。

    所有平台

  • 交握的形式化模型

    以 ProVerif 或 Tamarin 證明混合交握確實兌現它的承諾。

    所有平台

  • 後量子簽章

    裝置金鑰在 Ed25519 之外加入 ML-DSA-65，即使未來的量子電腦也無法冒充你。

    所有平台

  • 社群中繼伺服器

    願意的使用者可以從一份已簽署的清單中選用他人營運的中繼伺服器。

    所有平台
