新功能

Android 0.3.0-beta.7

  • 可從任何應用程式（如相簿或檔案）將檔案分享到 TotalDrop。長按應用程式圖示可選擇傳送、接收和傳送剪貼簿。
  • 傳送文字：直接輸入、從其他應用程式分享，或在選取的文字上選擇「用 TotalDrop 傳送」。收到的文字只顯示、不儲存，並可複製。
  • 驗證詞上方的標題在窄螢幕上也能完整顯示。
  • 手機不再連線到對方裝置不會使用的中繼。

Linux 0.3.0-beta.6

  • 傳送文字：傳送畫面上的「傳送文字」，或應用程式啟動器選單中的「傳送剪貼簿」，後者會開啟已填入剪貼簿文字的傳送畫面。收到的文字只會顯示、不會儲存；隱藏字元以名稱顯示，「複製文字」會照原樣複製。命令列：totaldrop send --text "…"，標準輸入中的文字用 totaldrop send -。
  • 從檔案管理員傳送：Dolphin、Nemo 和「檔案」（需安裝 nautilus-python）的右鍵選單中有「用 TotalDrop 傳送」。在工作列或啟動器中於 TotalDrop 上按右鍵，可選「傳送檔案」「接收檔案」和「傳送剪貼簿」。Flatpak 中沒有這些選單。
  • Flatpak：適用於 x86-64 和 ARM64；安裝時不會變更系統，唯讀系統上也能安裝，只存取網路、~/Downloads/TotalDrop、你選擇的檔案和少數桌面服務。
  • 處處是你的語言：軟體中心以應用程式的全部 35 種語言介紹 TotalDrop。Qt 6.11 以上版本中，文字欄位的右鍵選單使用應用程式的語言。設定中說明代碼與驗證詞維持英文。
  • 安全性：當接收裝置使用其他中繼或不使用中繼時，傳送裝置不再連線到自己的中繼；該中繼不再能看到傳送者的 IP 位址。命令列會以名稱顯示錯誤詳細資料中的控制字元，而不是把它們傳給終端機（GHSA-c6jh-7p7q-8gg4）。

確認你安裝的內容

  • 請只從 Google Play、本頁面或專案的 GitHub 發行版取得 TotalDrop。我們不在其他任何地方發布。
  • 在 Linux 上，以 sudo pacman -U、sudo apt install ./ 或 sudo dnf install ./ 加上檔名來安裝下載的檔案。
  • Flatpak 不需 sudo 即可安裝：flatpak install --user ./totaldrop-*.flatpak
  • GitHub 上的每個發行版都列出了 SHA-256 檢查碼。執行檔案前請先比對。
  • 一切都從公開的原始碼建置，你可以閱讀程式碼並自行建置。

TotalDrop 是開放原始碼軟體，以公開的方式開發。
