工作如何被檢查

  1. 日常變更都從公開的 issue 開始，只能透過拉取請求進入應用程式。

  2. 每個拉取請求都要通過自動檢查，並由不是作者的人或 AI 代理審查。

  3. 維護者合併已審查的變更，只有專案負責人可以核准發行和部署。發行版本由 GitHub Actions 建置，從不在個人電腦上建置。
