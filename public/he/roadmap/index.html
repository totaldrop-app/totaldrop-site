מה מגיע ל־TotalDrop

התאריכים הם יעדים, לא הבטחות: תכונה יוצאת רק כשהיא בטוחה. אפשר לעקוב אחרי כל שלב במאגר הפתוח.

הושלם

אוקטובר 2026

  • פרוטוקול פתוח

    פרוטוקול TotalDrop v0: קודי העברה עם CPace, Noise XXpsk3 עם ML-KEM-768 פוסט־קוונטי, ו־QUIC עם מפתחות חד־פעמיים. מתועד בכתב, כך שכל אחד יכול לבנות אפליקציה תואמת.

    כל הפלטפורמות

  • לקוח שורת פקודה

    שליחה וקבלה מהמסוף ב־Linux, ב־macOS וב־Windows.

    Linux · macOS · Windows

  • בטא ל־Android

    שליחה וקבלה עם קוד, בשפה שלך, בהתאם לצבעי הטלפון. ב־Google Play בהזמנה.

    Android

  • אפליקציית Linux

    Qt 6 ו־Wayland מקורי. עוקב בזמן אמת אחרי ערכת הנושא של KDE Plasma, Hyprland ו־Omarchy. חבילות ל־Arch, ל־Debian, ל־Ubuntu ול־Fedora.

    Linux

  • דרך חומות אש

    שני המכשירים מאזינים ומחייגים, כך שחומת אש בצד אחד כבר לא עוצרת העברה.

    כל הפלטפורמות

  • דרך האינטרנט

    המכשירים מגלים את הכתובת הציבורית שלהם עם STUN ומתחברים ישירות דרך רוב הנתבים הביתיים. כשזה בלתי אפשרי, התעבורה המוצפנת עוברת דרך שרת הממסר שלנו ב־Cloudflare, שאינו יכול לקרוא אותה.

    כל הפלטפורמות

  • מצב פרטיות בשורת הפקודה

    רק דרך הממסר: הצד השני לעולם לא יודע את כתובת ה־IP שלך.

    Linux · macOS · Windows

  • מצב פרטיות באפליקציות

    מתג אחד בהגדרות: הכול עובר דרך שרת הממסר, כך שהמכשיר השני לעולם לא יודע את כתובת ה־IP שלך.

    Android · Linux

  • Linux על ARM

    חבילות .deb ו־.rpm למחשבי ARM64 כמו Snapdragon X ו־NVIDIA RTX Spark.

    Linux

  • בשפה שלך

    האפליקציות והאתר הזה ב־35 שפות, עם תבניות המספרים של האזור שלך. דוברים ילידיים בודקים את הטיוטות.

    כל הפלטפורמות
