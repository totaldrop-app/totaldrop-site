    • השתמשו בחבילת Linux אחת בכל פעם. ל־Flatpak ולחבילת .pkg, .deb או .rpm יש שם משותף, ולכן כשאחת פתוחה, הפעלת השנייה מביאה לחזית את החלון הפתוח במקום לפתוח חלון שני.

    הכפתורים למעלה מיועדים ל־x86-64. עבור ARM64: Debian, Ubuntu (.deb, ARM64) · Fedora (.rpm, ARM64) · Flatpak (ARM64)

מה חדש

Android 0.3.0-beta.7

  • שתפו קבצים ל־TotalDrop מכל אפליקציה, כמו הגלריה או הקבצים. לחיצה ארוכה על סמל האפליקציה מציעה שליחה, קבלה ושליחת הלוח.
  • שלחו טקסט: הקלידו אותו, שתפו אותו מאפליקציה אחרת או בחרו „שליחה עם TotalDrop” בטקסט מסומן. טקסט שמגיע מוצג ולא נשמר, ואפשר להעתיק אותו.
  • הכותרת מעל מילות האימות נכנסת במסכים צרים.
  • הטלפון כבר לא מתחבר לממסר שהמכשיר השני לא ישתמש בו.

Linux 0.3.0-beta.6

  • שליחת טקסט: „שליחת טקסט” במסך השליחה, או „שליחת הלוח” בתפריט המפעיל של היישום, שפותח את מסך השליחה עם הטקסט מהלוח. טקסט שמגיע מוצג, לא נשמר; תווים מוסתרים מוצגים בשמם, ו„העתקת הטקסט” מעתיקה אותו בדיוק כפי שהגיע. בשורת הפקודה: totaldrop send --text "…", או totaldrop send - לטקסט מהקלט התקני.
  • שליחה ממנהל הקבצים: „שליחה עם TotalDrop” בתפריט הלחיצה הימנית של Dolphin, Nemo ו־Files (עם nautilus-python). לחיצה ימנית על TotalDrop בשורת המשימות או במפעיל מציעה „שליחת קבצים”, „קבלת קבצים” ו„שליחת הלוח”. תפריטים אלה אינם ב־Flatpak.
  • Flatpak: ל־x86-64 ול־ARM64; מותקן בלי לגעת במערכת, גם כשהמערכת לקריאה בלבד, וניגש רק לרשת, ל־~/Downloads/TotalDrop, לקבצים שבחרתם ולכמה שירותי שולחן עבודה.
  • השפה שלכם בכל מקום: מרכזי התוכנה מציגים את TotalDrop בכל 35 שפות היישום. עם Qt 6.11 ומעלה, תפריט הלחיצה הימנית של שדות טקסט הוא בשפת היישום. ההגדרות מציינות שהקודים ומילות האימות נשארים באנגלית.
  • אבטחה: מכשיר שולח כבר לא מתחבר לממסר שלו כשהמכשיר המקבל משתמש בממסר אחר או בלי ממסר; אותו ממסר כבר לא רואה את כתובת ה־IP של השולח. שורת הפקודה מציגה תווי בקרה בפרטי השגיאה בשמם במקום להעביר אותם למסוף (GHSA-c6jh-7p7q-8gg4).

בדיקת מה שמתקינים

  • יש להוריד את TotalDrop רק מ־Google Play, מהדף הזה או מהגרסאות של הפרויקט ב־GitHub. אנחנו לא מפרסמים בשום מקום אחר.
  • ב־Linux, מתקינים את הקובץ שהורד עם sudo pacman -U, sudo apt install ./ או sudo dnf install ./ ואחריו שם הקובץ.
  • Flatpak מותקן בלי sudo: flatpak install --user ./totaldrop-*.flatpak
  • כל גרסה ב־GitHub כוללת סיכומי ביקורת SHA-256. כדאי להשוות אותם לפני שמריצים קובץ.
  • הכול נבנה מקוד המקור הציבורי, שאפשר לקרוא ולבנות בעצמך.
