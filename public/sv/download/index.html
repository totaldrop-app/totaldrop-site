Nyheter

Android 0.3.0-beta.7

  • Dela filer till TotalDrop från valfri app, t.ex. Galleri eller Filer. Håll ned appikonen för Skicka, Ta emot och Skicka urklipp.
  • Skicka en text: skriv den, dela den från en annan app eller välj ”Skicka med TotalDrop” på markerad text. En mottagen text visas, sparas inte och kan kopieras.
  • Rubriken ovanför verifieringsorden får plats på smala skärmar.
  • Telefonen ansluter inte längre till ett relä som den andra enheten inte använder.

Linux 0.3.0-beta.6

  • Skicka text: ”Skicka text” på sändskärmen, eller ”Skicka urklipp” i appens startmeny, som öppnar sändskärmen med texten från urklipp. En text som kommer visas, sparas inte; dolda tecken visas med namn, och ”Kopiera text” kopierar den exakt som den kom. På kommandoraden: totaldrop send --text "…", eller totaldrop send - för text från standard in.
  • Skicka från filhanteraren: ”Skicka med TotalDrop” i högerklicksmenyn i Dolphin, Nemo och Filer (med nautilus-python). Högerklick på TotalDrop i aktivitetsfältet eller programstartaren ger ”Skicka filer”, ”Ta emot filer” och ”Skicka urklipp”. Menyerna finns inte i Flatpak-paketet.
  • Flatpak: för x86-64 och ARM64; installeras utan att röra systemet, även där systemet är skrivskyddat, och når bara nätverket, ~/Downloads/TotalDrop, filerna du väljer och några skrivbordstjänster.
  • Ditt språk överallt: programcentraler beskriver TotalDrop på alla appens 35 språk. Med Qt 6.11 eller senare är högerklicksmenyn i textfält på appens språk. Inställningar säger att koder och verifieringsord förblir på engelska.
  • Säkerhet: en sändande enhet ansluter inte längre till sitt relä när den mottagande använder ett annat eller inget; det reläet ser inte längre avsändarens IP-adress. Kommandoraden visar styrtecken i feldetaljer med namn i stället för att skicka dem till terminalen (GHSA-c6jh-7p7q-8gg4).

Kontrollera det du installerar

  • Hämta TotalDrop bara från Google Play, från den här sidan eller från projektets versioner på GitHub. Vi publicerar ingen annanstans.
  • I Linux installerar du den nedladdade filen med sudo pacman -U, sudo apt install ./ eller sudo dnf install ./ följt av filnamnet.
  • En Flatpak installeras utan sudo: flatpak install --user ./totaldrop-*.flatpak
  • Varje version på GitHub listar SHA-256-kontrollsummor. Jämför dem innan du kör en fil.
  • Allt byggs från den öppna källkoden, som du kan läsa och bygga själv.

TotalDrop är öppen källkod och utvecklas öppet.
