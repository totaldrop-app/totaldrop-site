新功能

Android 0.3.0-beta.7

  • 可从任何应用（如图库或文件）将文件分享到 TotalDrop。长按应用图标可选择发送、接收和发送剪贴板。
  • 发送文本：直接输入、从其他应用分享，或在选中的文本上选择“用 TotalDrop 发送”。收到的文本只显示、不保存，并可复制。
  • 验证词上方的标题在窄屏上也能完整显示。
  • 手机不再连接对方设备不会使用的中继。

Linux 0.3.0-beta.6

  • 发送文本：发送界面上的“发送文本”，或应用启动器菜单中的“发送剪贴板”，后者会打开已填入剪贴板文本的发送界面。收到的文本只显示、不保存；隐藏字符以名称显示，“复制文本”会按原样复制。命令行：totaldrop send --text "…"，标准输入中的文本用 totaldrop send -。
  • 从文件管理器发送：Dolphin、Nemo 和“文件”（需安装 nautilus-python）的右键菜单中有“用 TotalDrop 发送”。在任务栏或启动器中右键单击 TotalDrop，可选“发送文件”“接收文件”和“发送剪贴板”。Flatpak 中没有这些菜单。
  • Flatpak：适用于 x86-64 和 ARM64；安装时不改动系统，只读系统上也能安装，只访问网络、~/Downloads/TotalDrop、你选择的文件和少数桌面服务。
  • 处处是你的语言：软件中心以应用的全部 35 种语言介绍 TotalDrop。Qt 6.11 及以上版本中，文本框的右键菜单使用应用的语言。设置中说明代码和验证词保持英文。
  • 安全：当接收设备使用其他中继或不使用中继时，发送设备不再连接自己的中继；该中继不再能看到发送者的 IP 地址。命令行会以名称显示错误详情中的控制字符，而不是把它们传给终端（GHSA-c6jh-7p7q-8gg4）。

核实你安装的内容

  • 请只从 Google Play、本页面或项目的 GitHub 发行版获取 TotalDrop。我们不在其他任何地方发布。
  • 在 Linux 上，用 sudo pacman -U、sudo apt install ./ 或 sudo dnf install ./ 加上文件名来安装下载的文件。
  • Flatpak 无需 sudo 即可安装：flatpak install --user ./totaldrop-*.flatpak
  • GitHub 上的每个发行版都列出了 SHA-256 校验和。运行文件前请先比对。
  • 一切都从公开的源代码构建，你可以阅读代码并自行构建。
