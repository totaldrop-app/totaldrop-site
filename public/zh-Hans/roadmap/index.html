路线图 · 更新于 2026年10月30日

TotalDrop 即将推出的功能

日期是目标，不是承诺：功能只有在安全时才会发布。每一步都可以在公开仓库中跟进。

已完成

2026年10月

  • 开放协议

    TotalDrop Protocol v0：基于 CPace 的传输代码，结合后量子 ML-KEM-768 的 Noise XXpsk3，以及使用一次性密钥的 QUIC。已写成文档，任何人都能开发兼容的应用。

    所有平台

  • 命令行客户端

    在 Linux 终端中发送和接收，或通过 Cargo 从源码构建（计划提供 macOS 和 Windows 预编译二进制文件）。

    Linux

  • Android 测试版

    用代码发送和接收，使用你的语言，跟随手机的配色。在 Google Play 上通过邀请提供。

    Android

  • Linux 应用

    Qt 6 与原生 Wayland。实时跟随 KDE Plasma、Hyprland 和 Omarchy 的主题。提供 Arch、Debian、Ubuntu 和 Fedora 软件包。

    Linux

  • 穿越防火墙

    两台设备都会监听并主动连接，因此一方的防火墙不会再阻止传输。

    所有平台

  • 通过互联网

    设备通过 STUN 获知自己的公网地址，并能穿过大多数家用路由器直接连接。无法直连时，加密流量会经过我们部署在 Cloudflare 上的中继服务器，中继无法读取内容。

    所有平台

  • 命令行中的隐私模式

    仅使用中继：对方永远不会知道你的 IP 地址。

    Linux

  • 应用中的隐私模式

    设置中的一个开关：所有内容都经由中继服务器，对方设备永远不会知道你的 IP 地址。

    Android · Linux

  • ARM 上的 Linux

    适用于 Snapdragon X 和 NVIDIA RTX Spark 等 ARM64 电脑的 .deb 和 .rpm 软件包。

    Linux

  • 使用你的语言

    应用和本网站支持 35 种语言，并使用你所在地区的数字格式。母语者正在检查草稿。

    所有平台
现在

2026年11月

  • 用相机扫描二维码

    无需输入代码，把手机对准发送方的屏幕即可。

    Android

  • 在浏览器中接收

    打开链接，输入代码，保存文件。无需安装，依然端到端加密。

    Web
接下来

2026–27 年冬季

  • 继续中断的传输

    连接中断后会从中断处继续，不会重复发送已经收到的部分。

    所有平台

  • 从中继切换为直连

    经由中继开始的传输，一旦有直接路径可用，就会立即切换过去。

    所有平台

  • Windows 应用

    原生 Windows 11 应用。待捐款足以支付证书后进行签名。

    Windows

  • Arch User Repository

    用你的 AUR 助手安装和更新。

    Linux
以后

2027年

  • iPhone、iPad 和 Mac

    待捐款足以支付 Apple 开发者账号后推出原生应用。

    iOS · macOS

  • 链接与离线送达

    发送给不在线的人：加密副本最多等待 7 天，只有链接能打开它。

    所有平台

  • 服务器从不保存的账号

    可选：无需邮箱、手机号、密码，也无需输入任何号码。账号由你的设备保存；你自己的设备之间，以及已保存的联系人向你，都无需代码即可发送。

    所有平台

  • 已保存的联系人

    配对一次，核对四个单词，之后再给这个人发送就无需代码。

    所有平台

  • 通过 Tor 的隐私模式

    通过 Tor 连接中继服务器，并对大小进行填充，连我们的服务器也看不到你的 IP 地址。

    所有平台
1.0 版本

审计之后

  • 独立安全审计

    由外部公司审查协议、密码学实现以及处理不可信输入的代码。完整报告将会公开。

    所有平台

  • 握手的形式化模型

    用 ProVerif 或 Tamarin 证明混合握手兑现了它的承诺。

    所有平台

  • 后量子签名

    设备密钥在 Ed25519 之外增加 ML-DSA-65，即使未来的量子计算机也无法冒充你。

    所有平台

  • 社区中继

    愿意的用户可以从一份签名列表中选用他人运营的中继服务器。

    所有平台
