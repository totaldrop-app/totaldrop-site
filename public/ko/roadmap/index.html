TotalDrop에 다가올 것들

날짜는 목표일 뿐 약속이 아닙니다. 기능은 안전할 때만 출시됩니다. 모든 진행 상황은 공개 저장소에서 확인할 수 있습니다.

완료

2026년 10월

  • 개방형 프로토콜

    TotalDrop Protocol v0: CPace 기반 전송 코드, 양자 내성 ML-KEM-768을 더한 Noise XXpsk3, 일회용 키를 사용하는 QUIC. 누구나 호환 앱을 만들 수 있도록 문서로 정리했습니다.

    모든 플랫폼

  • 명령줄 클라이언트

    Linux, macOS, Windows 터미널에서 보내고 받기.

    Linux · macOS · Windows

  • Android 베타

    코드로 보내고 받기. 사용자의 언어로 표시되며 휴대전화의 색상을 따릅니다. Google Play에서 초대제로 제공.

    Android

  • Linux 앱

    Qt 6와 네이티브 Wayland. KDE Plasma, Hyprland, Omarchy의 테마를 실시간으로 따릅니다. Arch, Debian, Ubuntu, Fedora용 패키지.

    Linux

  • 방화벽 통과

    두 기기가 모두 연결을 기다리고 시도하므로, 한쪽의 방화벽 때문에 전송이 멈추지 않습니다.

    모든 플랫폼

  • 인터넷을 통해

    기기는 STUN으로 자신의 공개 주소를 확인하고, 대부분의 가정용 공유기 너머로 직접 연결됩니다. 그럴 수 없으면 암호화된 트래픽이 Cloudflare에 있는 저희 릴레이를 거치며, 릴레이는 내용을 읽을 수 없습니다.

    모든 플랫폼

  • 명령줄의 개인정보 보호 모드

    릴레이만 사용: 상대방은 내 IP 주소를 알 수 없습니다.

    Linux · macOS · Windows

  • 앱의 개인정보 보호 모드

    설정의 스위치 하나로 모든 전송이 릴레이를 거치므로, 상대 기기는 내 IP 주소를 알 수 없습니다.

    Android · Linux

  • ARM용 Linux

    Snapdragon X, NVIDIA RTX Spark 같은 ARM64 컴퓨터용 .deb 및 .rpm 패키지.

    Linux

  • 사용자의 언어로

    앱과 이 사이트를 35개 언어로, 사용자 지역의 숫자 형식에 맞춰 제공합니다. 원어민이 초안을 확인하고 있습니다.

    모든 플랫폼

2026년 11월

    코드를 입력하는 대신 휴대전화를 보내는 사람의 화면에 대세요.

    Android

    링크를 열고, 코드를 입력하고, 파일을 저장하세요. 설치할 것이 없으며 여전히 종단간 암호화됩니다.

    Web
다음

2026–27년 겨울

  • 중단된 전송 이어 받기

    연결이 끊겨도 이미 도착한 부분을 다시 보내지 않고 멈춘 곳부터 이어 갑니다.

    모든 플랫폼

  • 릴레이에서 직접 연결로 전환

    릴레이로 시작된 전송도 직접 경로가 열리는 즉시 그쪽으로 옮겨 갑니다.

    모든 플랫폼

    Windows 11용 네이티브 앱. 후원금으로 인증서 비용이 마련되면 서명됩니다.

    Windows

  • Arch User Repository

    AUR 도우미로 설치하고 업데이트하세요.

    Linux
나중에

2027년

  • iPhone, iPad, Mac

    후원금으로 Apple 개발자 계정 비용이 마련되면 네이티브 앱을 제공합니다.

    iOS · macOS

  • 링크와 오프라인 전달

    온라인이 아닌 사람에게도 보내세요. 암호화된 사본이 최대 7일 동안 기다리며, 링크로만 열 수 있습니다.

    모든 플랫폼

  • 서버가 절대 보관하지 않는 계정

    선택 사항: 이메일, 전화번호, 비밀번호, 입력할 번호가 없습니다. 계정은 기기가 직접 보관하며, 내 기기끼리 그리고 저장한 연락처에서 나에게 코드 없이 보낼 수 있습니다.

    모든 플랫폼

  • 저장된 연락처

    한 번 페어링하고 네 단어를 확인하면, 다음부터는 그 사람에게 코드 없이 보낼 수 있습니다.

    모든 플랫폼

  • Tor를 통한 개인정보 보호 모드

    릴레이에 Tor를 통해 연결하고 크기도 패딩으로 감추므로, 저희 서버조차 IP 주소를 볼 수 없습니다.

    모든 플랫폼
