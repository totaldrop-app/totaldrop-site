파일을 다른 기기로 바로 보내세요.

TotalDrop은 파일을 내 기기에서 상대 기기로 직접, 종단간 암호화하여 옮깁니다. 짧은 코드만 공유하면 중간의 누구도 보낸 내용을 읽을 수 없습니다. 계정도, 이메일도, 전화번호도 필요 없습니다.

TotalDrop을 쓰는 이유

  • 아무것도 업로드하지 않습니다

    파일은 내 기기에서 상대 기기로 갑니다. 기업 서버에서 기다리는 사본도, 일주일 뒤 만료되는 링크도 없습니다.

  • 계정은 절대 필요 없습니다

    이메일도, 전화번호도, 가입도 필요 없습니다. 두 기기에 필요한 것은 짧은 코드 하나뿐입니다.

  • 모든 플랫폼, 하나의 앱

    현재는 Android, Linux, 명령줄을 지원하며 Windows, macOS, iOS도 준비 중입니다. 휴대전화에서 노트북으로, 어떤 브랜드에서 어떤 브랜드로든.

  • 저희가 정한 크기 제한 없음

    폴더 전체, 긴 동영상, 원본 화질 사진까지. 한도를 정하는 것은 내 디스크와 연결뿐입니다.

  • 신뢰가 아닌 검증

    두 화면의 네 단어가 중간에 아무도 없다는 것을 증명합니다. 암호화는 종단간이며 양자 내성을 갖췄습니다.

  • 영원히 무료이고 개방적

    GPL 오픈 소스이며 후원으로 운영됩니다. 광고도, 추적도, 유료 등급도 없습니다.

세 단계

  1. 파일 선택

    종류도 개수도 상관없습니다. 받는 사람은 내가 선택한 것만 받습니다.

  2. 코드 공유

    7-harbor-rocket처럼 숫자 하나와 단어 두 개로 이루어집니다. 한 번만 쓸 수 있고 그 뒤에는 만료됩니다.

  3. 네 단어 비교

    두 화면에 같은 네 단어가 표시됩니다. 일치하면 그 연결은 두 사람만의 것입니다.

인터넷을 통해서도 두 기기는 가능한 한 직접 연결됩니다. 공유기나 방화벽이 가로막으면 암호화된 전송은 저희 릴레이를 거치며, 릴레이는 내용을 읽을 수 없습니다.

나와 받는 사람만 열 수 있습니다

보내기 전에 암호화
파일은 내 기기에서 암호화되고 받는 사람의 기기에서만 복호화됩니다. 키는 다른 어디에도 존재하지 않습니다.
코드는 오프라인으로 추측할 수 없습니다
코드는 PAKE 핸드셰이크를 통해 키로 바뀌므로, 잘못 추측하면 즉시 실패하고 그 시도는 무효가 됩니다. 키 교환에는 양자 내성 ML-KEM도 포함됩니다.
저희 서버는 소개만 합니다
서버는 IP 주소와 코드의 숫자만 볼 뿐, 단어, 파일 이름, 파일은 절대 보지 않습니다. 로그도 남기지 않습니다.
누구나 확인할 수 있는 코드
모든 코드 줄이 공개되어 있습니다. 버전 1.0은 독립 보안 감사를 거친 후에만 출시됩니다.
