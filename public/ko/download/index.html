TotalDrop 다운로드

무료, 오픈 소스, 계정 없음. 기기를 선택하세요. 지금 사용 중인 기기에 표시가 되어 있습니다.

플랫폼

  • 이 기기용

    Android

    베타

    모든 기능을 갖춘 앱으로, 사용자의 언어로 표시되며 휴대전화의 색상을 따릅니다.

    • Android 15 이상, 64비트
    • 베타가 비공개인 동안 Google Play에서 초대제로 테스트
    베타 참여 요청
  • 이 기기용

    명령줄

    사용 가능

    Linux, macOS, Windows 터미널용. 파일과 폴더 전체를 보낼 수 있습니다.

    cargo install --locked \
  --git https://github.com/totaldrop-app/totaldrop \
  totaldrop-cli
    totaldrop send ~/Photos/trip
totaldrop receive 7-harbor-rocket
  • 이 기기용

    Linux 앱

    베타

    Wayland용으로 Qt 6로 만들었습니다. 색상, 글꼴, 아이콘을 데스크톱(Plasma, Hyprland, Omarchy, GNOME)에서 가져옵니다.

    • 배포판 계열마다 별도 패키지: 모두 x86-64용이 있고, Debian, Ubuntu, Fedora는 ARM64용도 있습니다
    • .pkg, .deb, .rpm 패키지는 totaldrop 명령도 설치합니다
    • Linux 패키지는 한 번에 하나만 사용하세요. Flatpak과 .pkg, .deb 또는 .rpm 패키지는 같은 이름을 쓰기 때문에, 하나가 열려 있을 때 다른 하나를 실행하면 두 번째 창이 열리지 않고 열려 있는 창이 앞으로 나옵니다.
    Arch, Omarchy, Manjaro Debian, Ubuntu (.deb) Fedora (.rpm) Flatpak

    위의 버튼은 x86-64용입니다. ARM64용: Debian, Ubuntu (.deb, ARM64) · Fedora (.rpm, ARM64) · Flatpak (ARM64)

새로운 기능

Android 0.3.0-beta.7

  • 갤러리나 파일 등 어떤 앱에서든 TotalDrop으로 파일을 공유하세요. 앱 아이콘을 길게 누르면 보내기, 받기, 클립보드 보내기가 나옵니다.
  • 텍스트 보내기: 직접 입력하거나 다른 앱에서 공유하거나, 선택한 텍스트에서 'TotalDrop으로 보내기'를 고르세요. 받은 텍스트는 저장되지 않고 표시되며 복사할 수 있습니다.
  • 확인 단어 위의 제목이 좁은 화면에도 맞게 표시됩니다.
  • 상대 기기가 쓰지 않을 릴레이에는 더 이상 연결하지 않습니다.

Linux 0.3.0-beta.6

  • 텍스트 보내기: 보내기 화면의 "텍스트 보내기", 또는 앱 실행기 메뉴의 "클립보드 보내기"(클립보드의 텍스트가 채워진 보내기 화면을 엽니다). 도착한 텍스트는 저장되지 않고 표시되며, 숨겨진 문자는 이름으로 보이고, "텍스트 복사"는 도착한 그대로 복사합니다. 명령줄에서는 totaldrop send --text "…", 표준 입력의 텍스트는 totaldrop send -.
  • 파일 관리자에서 보내기: Dolphin, Nemo, 파일(nautilus-python 설치 시)의 오른쪽 클릭 메뉴에 "TotalDrop으로 보내기". 작업 표시줄이나 실행기에서 TotalDrop을 오른쪽 클릭하면 "파일 보내기", "파일 받기", "클립보드 보내기". 이 메뉴들은 Flatpak에는 없습니다.
  • Flatpak: x86-64와 ARM64용. 시스템을 건드리지 않고, 읽기 전용 시스템에서도 설치되며, 네트워크, ~/Downloads/TotalDrop, 고른 파일, 몇 가지 데스크톱 서비스에만 접근합니다.
  • 어디서나 내 언어: 소프트웨어 센터가 앱의 35개 언어 모두로 TotalDrop을 소개합니다. Qt 6.11 이상에서는 텍스트 필드의 오른쪽 클릭 메뉴가 앱의 언어로 나옵니다. 설정에서는 코드와 확인 단어가 영어로 유지된다고 알려 줍니다.
  • 보안: 받는 기기가 다른 릴레이를 쓰거나 쓰지 않으면, 보내는 기기는 더 이상 자기 릴레이에 연결하지 않습니다. 그 릴레이는 더 이상 보낸 사람의 IP 주소를 보지 못합니다. 명령줄은 오류 세부 정보의 제어 문자를 터미널에 넘기지 않고 이름으로 보여 줍니다(GHSA-c6jh-7p7q-8gg4).

설치할 파일 확인하기

  • TotalDrop은 Google Play, 이 페이지 또는 프로젝트의 GitHub 릴리스에서만 받으세요. 다른 곳에는 배포하지 않습니다.
  • Linux에서는 다운로드한 파일을 sudo pacman -U, sudo apt install ./ 또는 sudo dnf install ./ 뒤에 파일 이름을 붙여 설치하세요.
  • Flatpak은 sudo 없이 설치됩니다: flatpak install --user ./totaldrop-*.flatpak
  • GitHub의 모든 릴리스에는 SHA-256 체크섬이 나와 있습니다. 파일을 실행하기 전에 비교하세요.
  • 모든 것은 공개된 소스 코드로 빌드됩니다. 코드를 읽고 직접 빌드할 수도 있습니다.
