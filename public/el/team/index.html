Πώς ελέγχεται η δουλειά

  1. Οι καθημερινές αλλαγές ξεκινούν ως δημόσιο issue και φτάνουν στην εφαρμογή μόνο μέσω pull request.

  2. Κάθε pull request περνά από τους αυτόματους ελέγχους και από έλεγχο ενός ανθρώπου ή ενός πράκτορα ΤΝ που δεν το έγραψε.

  3. Μόνο ο επικεφαλής του έργου συγχωνεύει, εκδίδει και αναπτύσσει. Οι εκδόσεις χτίζονται από το GitHub Actions, ποτέ σε προσωπικό υπολογιστή.
