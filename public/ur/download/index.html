نیا کیا ہے

Android 0.3.0-beta.7

  • کسی بھی ایپ، جیسے گیلری یا فائلز، سے TotalDrop پر فائلیں شیئر کریں۔ ایپ کے آئیکن کو دبائے رکھنے پر بھیجیں، وصول کریں اور کلپ بورڈ بھیجیں آتے ہیں۔
  • متن بھیجیں: اسے لکھیں، کسی دوسری ایپ سے شیئر کریں یا منتخب متن پر «TotalDrop سے بھیجیں» چنیں۔ آنے والا متن دکھایا جاتا ہے، محفوظ نہیں ہوتا، اور کاپی کیا جا سکتا ہے۔
  • تصدیقی الفاظ کے اوپر کا عنوان تنگ اسکرینوں پر سما جاتا ہے۔
  • آپ کا فون اب ایسے ریلے سے نہیں جڑتا جسے دوسرا آلہ استعمال نہیں کرے گا۔

Linux 0.3.0-beta.6

  • متن بھیجنا: بھیجنے کی اسکرین پر "متن بھیجیں"، یا ایپ کے لانچر مینو میں "کلپ بورڈ بھیجیں"، جو کلپ بورڈ کے متن کے ساتھ بھیجنے کی اسکرین کھولتا ہے۔ آنے والا متن دکھایا جاتا ہے، محفوظ نہیں ہوتا؛ چھپے حروف اپنے نام سے دکھتے ہیں، اور "متن کاپی کریں" اسے بالکل ویسا ہی کاپی کرتا ہے جیسا وہ آیا۔ کمانڈ لائن پر: totaldrop send --text "…"، یا معیاری ان پٹ کے متن کے لیے totaldrop send -۔
  • فائل منیجر سے بھیجنا: Dolphin، Nemo اور Files (nautilus-python کے ساتھ) کے رائٹ کلک مینو میں "TotalDrop سے بھیجیں"۔ ٹاسک بار یا لانچر میں TotalDrop پر رائٹ کلک کرنے سے "فائلیں بھیجیں"، "فائلیں وصول کریں" اور "کلپ بورڈ بھیجیں"۔ یہ مینو Flatpak میں نہیں ہیں۔
  • Flatpak: x86-64 اور ARM64 کے لیے؛ سسٹم کو چھوئے بغیر انسٹال ہوتا ہے، وہاں بھی جہاں سسٹم صرف پڑھنے کے لیے ہو، اور صرف نیٹ ورک، ~/Downloads/TotalDrop، آپ کی چنی ہوئی فائلوں اور چند ڈیسک ٹاپ خدمات تک پہنچتا ہے۔
  • ہر جگہ آپ کی زبان: سافٹ ویئر مراکز TotalDrop کا تعارف ایپ کی تمام 35 زبانوں میں کراتے ہیں۔ Qt 6.11 یا نئے میں متن کے خانوں کا رائٹ کلک مینو ایپ کی زبان میں ہے۔ سیٹنگز بتاتی ہیں کہ کوڈ اور تصدیقی الفاظ انگریزی میں ہی رہتے ہیں۔
  • حفاظت: بھیجنے والا آلہ اب اپنے ریلے سے نہیں جڑتا جب وصول کرنے والا کوئی دوسرا ریلے استعمال کرے یا کوئی نہیں؛ وہ ریلے اب بھیجنے والے کا IP پتہ نہیں دیکھتا۔ کمانڈ لائن غلطی کی تفصیل میں کنٹرول حروف کو ٹرمینل تک پہنچانے کے بجائے ان کے نام سے دکھاتی ہے (GHSA-c6jh-7p7q-8gg4)۔

جو انسٹال کریں اسے جانچ لیں

  • TotalDrop صرف Google Play، اس صفحے یا پروجیکٹ کی GitHub ریلیزز سے حاصل کریں۔ ہم اسے کہیں اور شائع نہیں کرتے۔
  • Linux پر ڈاؤن لوڈ کی گئی فائل کو sudo pacman -U، sudo apt install ./ یا sudo dnf install ./ اور اس کے نام کے ساتھ انسٹال کریں۔
  • Flatpak کے لیے sudo کی ضرورت نہیں: flatpak install --user ./totaldrop-*.flatpak
  • GitHub پر ہر ریلیز میں SHA-256 چیک سمز درج ہوتے ہیں۔ کوئی فائل چلانے سے پہلے ان کا موازنہ کریں۔
  • سب کچھ عوامی سورس کوڈ سے بنایا جاتا ہے، جسے آپ پڑھ سکتے ہیں اور خود بنا سکتے ہیں۔
