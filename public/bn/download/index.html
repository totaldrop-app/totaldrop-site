    কমান্ড লাইন

    পাওয়া যাচ্ছে

    আজ Linux প্যাকেজে প্রাক-নির্মিত, অথবা Cargo দিয়ে সোর্স থেকে তৈরি করা যায়। আর্গুমেন্ট বা স্ট্যান্ডার্ড ইনপুট থেকে ফাইল, পুরো ফোল্ডার ও টেক্সট পাঠায়।

    cargo install --locked \
  --git https://github.com/totaldrop-app/totaldrop \
  totaldrop-cli
    totaldrop send ~/Photos/trip
totaldrop send --text "hello"
totaldrop receive 7-harbor-rocket

    Linux অ্যাপ

    বিটা

    Wayland-এর জন্য Qt 6 দিয়ে তৈরি। এটি রঙ, ফন্ট ও আইকন আপনার ডেস্কটপ থেকে নেয়: Plasma, Hyprland, Omarchy, GNOME।

    • প্রতিটি ডিস্ট্রিবিউশন পরিবারের জন্য আলাদা প্যাকেজ: সবগুলো x86-64-এর জন্য; Debian, Ubuntu ও Fedora ARM64-এর জন্যও
    • .pkg, .deb ও .rpm প্যাকেজ totaldrop কমান্ড এবং Dolphin, Files ও Nemo-র রাইট-ক্লিক মেনুও ইনস্টল করে
    • একবারে একটি Linux প্যাকেজ ব্যবহার করুন। Flatpak এবং .pkg, .deb বা .rpm প্যাকেজের নাম একই, তাই একটি খোলা থাকলে অন্যটি চালু করলে দ্বিতীয় উইন্ডো খোলে না, খোলা উইন্ডোটি সামনে আসে।
    Arch, Omarchy, Manjaro Debian, Ubuntu (.deb) Fedora (.rpm) Flatpak

    ওপরের বোতামগুলো x86-64-এর জন্য। ARM64-এর জন্য: Debian, Ubuntu (.deb, ARM64) · Fedora (.rpm, ARM64) · Flatpak (ARM64)

নতুন কী

Android 0.3.0-beta.7

  • গ্যালারি বা ফাইলসের মতো যেকোনো অ্যাপ থেকে TotalDrop-এ ফাইল শেয়ার করুন। অ্যাপ আইকন চেপে ধরলে পাঠান, গ্রহণ করুন ও ক্লিপবোর্ডের লেখা পাঠান আসে।
  • লেখা পাঠান: লিখুন, অন্য অ্যাপ থেকে শেয়ার করুন, বা নির্বাচিত লেখায় "TotalDrop দিয়ে পাঠান" বেছে নিন। আসা লেখা দেখানো হয়, সেভ হয় না, এবং কপি করা যায়।
  • যাচাইয়ের শব্দগুলোর উপরের শিরোনাম সরু স্ক্রিনেও আঁটে।
  • আপনার ফোন আর এমন রিলেতে সংযুক্ত হয় না যা অন্য ডিভাইস ব্যবহার করবে না।

Linux 0.3.0-beta.6

  • লেখা পাঠানো: পাঠানোর পর্দায় "লেখা পাঠান", বা অ্যাপের লঞ্চার মেনুতে "ক্লিপবোর্ডের লেখা পাঠান", যা ক্লিপবোর্ডের লেখা বসিয়ে পাঠানোর পর্দা খোলে। আসা লেখা দেখানো হয়, সংরক্ষণ করা হয় না; লুকানো অক্ষর নাম দিয়ে দেখায়, আর "লেখা কপি করুন" সেটি ঠিক যেমন এসেছে তেমন কপি করে। কমান্ড লাইনে: totaldrop send --text "…", বা স্ট্যান্ডার্ড ইনপুটের লেখার জন্য totaldrop send -।
  • ফাইল ম্যানেজার থেকে পাঠানো: Dolphin, Nemo ও Files-এর (nautilus-python সহ) রাইট-ক্লিক মেনুতে "TotalDrop দিয়ে পাঠান"। টাস্কবার বা লঞ্চারে TotalDrop-এ রাইট-ক্লিক করলে "ফাইল পাঠান", "ফাইল গ্রহণ করুন" ও "ক্লিপবোর্ডের লেখা পাঠান"। এই মেনুগুলো Flatpak-এ নেই।
  • Flatpak: x86-64 ও ARM64-এর জন্য; সিস্টেমে হাত না দিয়ে ইনস্টল হয়, যেখানে সিস্টেম কেবল-পঠনযোগ্য সেখানেও, আর শুধু নেটওয়ার্ক, ~/Downloads/TotalDrop, আপনার বাছাই করা ফাইল ও কয়েকটি ডেস্কটপ সেবায় পৌঁছায়।
  • সব জায়গায় আপনার ভাষা: সফটওয়্যার কেন্দ্রগুলো অ্যাপের ৩৫টি ভাষাতেই TotalDrop-এর পরিচয় দেয়। Qt 6.11 বা নতুনে লেখার ঘরের রাইট-ক্লিক মেনু অ্যাপের ভাষায়। সেটিংস জানায় যে কোড ও যাচাইয়ের শব্দ ইংরেজিতেই থাকে।
  • নিরাপত্তা: যে ডিভাইস পাঠায় সেটি আর নিজের রিলেতে যুক্ত হয় না যখন গ্রহণকারী অন্য রিলে বা কোনো রিলে ব্যবহার করে না; সেই রিলে আর প্রেরকের IP ঠিকানা দেখে না। কমান্ড লাইন ত্রুটির বিবরণের নিয়ন্ত্রণ অক্ষর টার্মিনালে না দিয়ে নাম দিয়ে দেখায় (GHSA-c6jh-7p7q-8gg4)।

যা ইনস্টল করছেন তা যাচাই করুন

  • TotalDrop শুধু Google Play, এই পেজ অথবা প্রজেক্টের GitHub রিলিজ থেকে নিন। আমরা অন্য কোথাও প্রকাশ করি না।
  • Linux-এ ডাউনলোড করা ফাইলটি sudo pacman -U, sudo apt install ./ অথবা sudo dnf install ./ এবং তার নাম দিয়ে ইনস্টল করুন।
  • Flatpak ইনস্টল করতে sudo লাগে না: flatpak install --user ./totaldrop-*.flatpak
  • GitHub-এর প্রতিটি রিলিজে SHA-256 চেকসাম দেওয়া থাকে। কোনো ফাইল চালানোর আগে সেগুলো মিলিয়ে নিন।
  • সবকিছু সর্বজনীন সোর্স কোড থেকে তৈরি, যা আপনি নিজে পড়তে ও বিল্ড করতে পারেন।
