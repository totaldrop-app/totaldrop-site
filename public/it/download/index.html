    Riga di comando

    Disponibile

    Precompilato oggi nei pacchetti Linux, oppure compilabile dai sorgenti con Cargo. Invia file, intere cartelle e testo da argomenti o standard input.

    cargo install --locked \
  --git https://github.com/totaldrop-app/totaldrop \
  totaldrop-cli
    totaldrop send ~/Photos/trip
totaldrop send --text "hello"
totaldrop receive 7-harbor-rocket
  • Per questo dispositivo

    App per Linux

    Beta

    Realizzata con Qt 6 per Wayland. Prende colori, caratteri e icone dal tuo desktop: Plasma, Hyprland, Omarchy, GNOME.

    • Un pacchetto separato per ogni famiglia di distribuzioni: tutti per x86-64; Debian, Ubuntu e Fedora anche per ARM64
    • I pacchetti .pkg, .deb e .rpm installano anche il comando totaldrop e i menu del tasto destro per Dolphin, File e Nemo
    • Usa un solo pacchetto Linux alla volta. Il Flatpak e il pacchetto .pkg, .deb o .rpm condividono un nome, quindi mentre uno è aperto, avviare l'altro porta in primo piano la finestra aperta invece di aprirne una seconda.
    Arch, Omarchy, Manjaro Debian, Ubuntu (.deb) Fedora (.rpm) Flatpak

    I pulsanti qui sopra sono per x86-64. Per ARM64: Debian, Ubuntu (.deb, ARM64) · Fedora (.rpm, ARM64) · Flatpak (ARM64)

Novità

Android 0.3.0-beta.7

  • Condividi file con TotalDrop da qualsiasi app, come Galleria o File. Tenendo premuta l’icona compaiono Invia, Ricevi e Invia appunti.
  • Invia un testo: scrivilo, condividilo da un’altra app o scegli «Invia con TotalDrop» sul testo selezionato. Il testo ricevuto viene mostrato, non salvato, e si può copiare.
  • Il titolo sopra le parole di verifica entra negli schermi stretti.
  • Il telefono non si connette più a un server di inoltro che l’altro dispositivo non userà.

Linux 0.3.0-beta.6

  • Invia testo: «Invia testo» nella schermata di invio, oppure «Invia appunti» nel menu di avvio dell’app, che apre la schermata di invio con il testo degli appunti. Un testo in arrivo viene mostrato, non salvato; i caratteri nascosti sono indicati per nome e «Copia testo» lo copia esattamente com’è arrivato. Da riga di comando: totaldrop send --text "…", oppure totaldrop send - per il testo dallo standard input.
  • Invia dal gestore di file: «Invia con TotalDrop» nel menu contestuale di Dolphin, Nemo e File (con nautilus-python). Un clic destro su TotalDrop nella barra delle applicazioni o nel launcher offre «Invia file», «Ricevi file» e «Invia appunti». Questi menu non sono nel Flatpak.
  • Flatpak: per x86-64 e ARM64; si installa senza toccare il sistema, anche se è in sola lettura, e accede solo alla rete, a ~/Downloads/TotalDrop, ai file scelti e ad alcuni servizi del desktop.
  • La tua lingua, ovunque: i centri software descrivono TotalDrop in tutte le 35 lingue dell’app. Con Qt 6.11 o successivo, il menu contestuale dei campi di testo è nella lingua dell’app. Le impostazioni spiegano che codici e parole di verifica restano in inglese.
  • Sicurezza: un dispositivo che invia non si collega più al proprio relay se quello che riceve ne usa un altro o nessuno; quel relay non vede più l’indirizzo IP del mittente. La riga di comando indica per nome i caratteri di controllo nei dettagli degli errori invece di passarli al terminale (GHSA-c6jh-7p7q-8gg4).

Verifica ciò che installi

  • Scarica TotalDrop solo da Google Play, da questa pagina o dalle release GitHub del progetto. Non pubblichiamo da nessun'altra parte.
  • Su Linux, installa il file scaricato con sudo pacman -U, sudo apt install ./ o sudo dnf install ./ seguito dal suo nome.
  • Un Flatpak si installa senza sudo: flatpak install --user ./totaldrop-*.flatpak
  • Ogni release su GitHub riporta i checksum SHA-256. Confrontali prima di eseguire un file.
  • Tutto è compilato dal codice sorgente pubblico, che puoi leggere e compilare tu stesso.
