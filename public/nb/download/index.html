Nytt

Android 0.3.0-beta.7

  • Del filer til TotalDrop fra hvilken som helst app, for eksempel Galleri eller Filer. Hold inne appikonet for Send, Motta og Send utklippstavlen.
  • Send en tekst: skriv den, del den fra en annen app eller velg «Send med TotalDrop» på merket tekst. En mottatt tekst vises, lagres ikke og kan kopieres.
  • Overskriften over bekreftelsesordene får plass på smale skjermer.
  • Telefonen kobler seg ikke lenger til et relé som den andre enheten ikke vil bruke.

Linux 0.3.0-beta.6

  • Send tekst: «Send tekst» på sendeskjermen, eller «Send utklippstavlen» i appens startmeny, som åpner sendeskjermen med teksten fra utklippstavlen. En tekst som kommer, vises, lagres ikke; skjulte tegn vises med navn, og «Kopier tekst» kopierer den nøyaktig slik den kom. På kommandolinjen: totaldrop send --text "…", eller totaldrop send - for tekst fra standard inn.
  • Send fra filbehandleren: «Send med TotalDrop» i høyreklikkmenyen i Dolphin, Nemo og Filer (med nautilus-python). Høyreklikk på TotalDrop i oppgavelinjen eller programstarteren gir «Send filer», «Motta filer» og «Send utklippstavlen». Disse menyene finnes ikke i Flatpak-pakken.
  • Flatpak: for x86-64 og ARM64; installeres uten å røre systemet, også der systemet er skrivebeskyttet, og når bare nettverket, ~/Downloads/TotalDrop, filene du velger og noen få skrivebordstjenester.
  • Ditt språk overalt: programvaresentre beskriver TotalDrop på alle appens 35 språk. Med Qt 6.11 eller nyere er høyreklikkmenyen i tekstfelt på appens språk. Innstillinger sier at koder og bekreftelsesord forblir på engelsk.
  • Sikkerhet: en sendende enhet kobler seg ikke lenger til sitt relé når den mottakende bruker et annet eller ingen; det reléet ser ikke lenger avsenderens IP-adresse. Kommandolinjen viser kontrolltegn i feildetaljer med navn i stedet for å sende dem til terminalen (GHSA-c6jh-7p7q-8gg4).

Sjekk det du installerer

  • Hent TotalDrop bare fra Google Play, fra denne siden eller fra prosjektets versjoner på GitHub. Vi publiserer ikke noe annet sted.
  • På Linux installerer du den nedlastede filen med sudo pacman -U, sudo apt install ./ eller sudo dnf install ./ etterfulgt av filnavnet.
  • En Flatpak installeres uten sudo: flatpak install --user ./totaldrop-*.flatpak
  • Hver versjon på GitHub viser SHA-256-sjekksummer. Sammenlign dem før du kjører en fil.
  • Alt bygges fra den offentlige kildekoden, som du kan lese og bygge selv.
