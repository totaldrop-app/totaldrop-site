Envoyez un fichier directement à un autre appareil.

TotalDrop envoie les fichiers directement de votre appareil vers celui de votre destinataire, chiffrés de bout en bout. Vous partagez un code court ; aucun intermédiaire ne peut lire ce que vous envoyez. Pas de compte, pas d'e-mail, pas de numéro de téléphone.

Pourquoi TotalDrop

  • Rien n'est mis en ligne

    Les fichiers vont de votre appareil au sien. Aucune copie n'attend sur le serveur d'une entreprise, et aucun lien n'expire au bout d'une semaine.

  • Jamais de compte

    Pas d'e-mail, pas de numéro de téléphone, pas d'inscription. Un code court suffit à deux appareils.

  • Toutes les plateformes, une seule application

    Android, Linux et la ligne de commande aujourd'hui ; Windows, macOS et iOS en préparation. Du téléphone à l'ordinateur portable, de n'importe quelle marque à n'importe quelle autre.

  • Aucune limite de taille de notre part

    Des dossiers entiers, de longues vidéos, des photos en qualité originale. Seuls votre disque et votre connexion fixent la limite.

  • Vérifié, pas supposé fiable

    Quatre mots sur les deux écrans prouvent que personne ne s'est interposé. Le chiffrement est de bout en bout et post-quantique.

  • Libre et ouvert, pour de bon

    Open source sous GPL, financé par les dons. Pas de publicité, pas de pistage, pas d'offre premium.

Trois étapes

  1. Choisissez les fichiers

    De tout type, autant que vous voulez. Le destinataire ne reçoit que ce que vous avez choisi.

  2. Partagez le code

    Un nombre et deux mots, comme 7-harbor-rocket. Il fonctionne une fois, puis expire.

  3. Comparez quatre mots

    Les deux écrans affichent les quatre mêmes mots. S'ils correspondent, la connexion n'appartient qu'à vous.

Via Internet, les deux appareils se connectent directement chaque fois que c'est possible. Quand un routeur ou un pare-feu fait obstacle, le transfert chiffré passe par notre serveur relais, qui ne peut pas le lire.

Seuls vous et le destinataire pouvez l'ouvrir

Chiffré avant de partir
Les fichiers sont chiffrés sur votre appareil et déchiffrés uniquement sur celui du destinataire. Les clés n'existent nulle part ailleurs.
Le code ne peut pas être deviné hors ligne
Le code devient une clé grâce à une poignée de main PAKE : une mauvaise tentative échoue aussitôt et est grillée. L'échange de clés inclut ML-KEM post-quantique.
Notre serveur ne fait que présenter
Il voit votre adresse IP et le nombre du code, jamais les mots, les noms de fichiers ni les fichiers. Il ne conserve aucun journal.
Un code que chacun peut vérifier
Chaque ligne est publique. La version 1.0 ne sortira qu'après un audit de sécurité indépendant.
