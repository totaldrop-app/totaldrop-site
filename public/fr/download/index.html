Nouveautés

Android 0.3.0-beta.7

  • Partagez des fichiers vers TotalDrop depuis n’importe quelle app, comme Galerie ou Fichiers. Un appui long sur l’icône propose Envoyer, Recevoir et Envoyer le presse-papiers.
  • Envoyez un texte : tapez-le, partagez-le depuis une autre app ou choisissez « Envoyer avec TotalDrop » sur un texte sélectionné. Un texte reçu est affiché, non enregistré, et peut être copié.
  • Le titre au-dessus des mots de vérification tient sur les écrans étroits.
  • Votre téléphone ne se connecte plus à un relais que l’autre appareil n’utilisera pas.

Linux 0.3.0-beta.6

  • Envoyer du texte : « Envoyer du texte » sur l’écran d’envoi, ou « Envoyer le presse-papiers » dans le menu du lanceur de l’app, qui ouvre l’écran d’envoi avec le texte du presse-papiers. Un texte reçu est affiché, pas enregistré ; les caractères cachés sont nommés, et « Copier le texte » le copie tel qu’il est arrivé. En ligne de commande : totaldrop send --text "…", ou totaldrop send - pour le texte de l’entrée standard.
  • Envoyer depuis le gestionnaire de fichiers : « Envoyer avec TotalDrop » dans le menu contextuel de Dolphin, Nemo et Fichiers (avec nautilus-python). Un clic droit sur TotalDrop dans la barre des tâches ou le lanceur propose « Envoyer des fichiers », « Recevoir des fichiers » et « Envoyer le presse-papiers ». Ces menus ne sont pas dans le Flatpak.
  • Flatpak : pour x86-64 et ARM64 ; il s’installe sans toucher au système, même en lecture seule, et n’accède qu’au réseau, à ~/Downloads/TotalDrop, aux fichiers choisis et à quelques services du bureau.
  • Votre langue, partout : les logithèques décrivent TotalDrop dans les 35 langues de l’app. Avec Qt 6.11 ou plus récent, le menu contextuel des champs de texte est dans la langue de l’app. Les réglages indiquent que les codes et les mots de vérification restent en anglais.
  • Sécurité : un appareil qui envoie ne se connecte plus à son relais si l’appareil qui reçoit en utilise un autre ou aucun ; ce relais ne voit plus l’adresse IP de l’expéditeur. La ligne de commande nomme les caractères de contrôle des détails d’erreur au lieu de les transmettre au terminal (GHSA-c6jh-7p7q-8gg4).

Vérifiez ce que vous installez

  • Procurez-vous TotalDrop uniquement sur Google Play, sur cette page ou dans les versions GitHub du projet. Nous ne publions nulle part ailleurs.
  • Sous Linux, installez le fichier téléchargé avec sudo pacman -U, sudo apt install ./ ou sudo dnf install ./ suivi de son nom.
  • Un Flatpak s'installe sans sudo : flatpak install --user ./totaldrop-*.flatpak
  • Chaque version sur GitHub indique les sommes de contrôle SHA-256. Comparez-les avant d'exécuter un fichier.
  • Tout est compilé à partir du code source public, que vous pouvez lire et compiler vous-même.
