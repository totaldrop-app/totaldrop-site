Comment le travail est vérifié

  1. Les modifications courantes commencent par une issue publique et n'entrent dans l'application que par une pull request.

  2. Chaque pull request passe les vérifications automatiques et la revue d'une personne ou d'un agent d'IA qui ne l'a pas écrite.

  3. Seul le chef de projet fusionne, publie et déploie. Les versions sont compilées par GitHub Actions, jamais sur un ordinateur personnel.
