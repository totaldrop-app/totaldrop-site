Ce qui arrive dans TotalDrop

Les dates sont des objectifs, pas des promesses : une fonctionnalité ne sort que lorsqu'elle est sûre. Chaque étape peut être suivie dans le dépôt public.

Fait

Octobre 2026

  • Un protocole ouvert

    TotalDrop Protocol v0 : codes de transfert avec CPace, Noise XXpsk3 avec ML-KEM-768 post-quantique, QUIC avec des clés à usage unique. Documenté pour que chacun puisse créer une application compatible.

    Toutes les plateformes

  • Client en ligne de commande

    Envoyer et recevoir depuis un terminal Linux, ou compiler depuis les sources avec Cargo (binaires précompilés macOS et Windows prévus).

    Linux

  • Bêta Android

    Envoyer et recevoir avec un code, dans votre langue, aux couleurs du téléphone. Sur Google Play, sur invitation.

    Android

  • Application Linux

    Qt 6 et Wayland natif. Suit en direct le thème de KDE Plasma, Hyprland et Omarchy. Paquets pour Arch, Debian, Ubuntu et Fedora.

    Linux

  • À travers les pare-feu

    Les deux appareils écoutent et appellent, si bien qu'un pare-feu d'un côté n'empêche plus un transfert.

    Toutes les plateformes

  • Via Internet

    Les appareils trouvent leur adresse publique avec STUN et se connectent directement à travers la plupart des box. Quand c'est impossible, le trafic chiffré passe par notre serveur relais sur Cloudflare, qui ne peut pas le lire.

    Toutes les plateformes

  • Mode confidentialité en ligne de commande

    Relais uniquement : l'autre appareil ne connaît jamais votre adresse IP.

    Linux

  • Mode confidentialité dans les applications

    Un seul interrupteur dans les Paramètres : tout passe par le serveur relais, si bien que l'autre appareil ne connaît jamais votre adresse IP.

    Android · Linux

  • Linux sur ARM

    Paquets .deb et .rpm pour les ordinateurs ARM64 comme Snapdragon X et NVIDIA RTX Spark.

    Linux

  • Dans votre langue

    Les applications et ce site en 35 langues, avec les formats de nombres de votre région. Des locuteurs natifs vérifient les ébauches.

    Toutes les plateformes

Ensuite

Hiver 2026–27

  • Reprendre les transferts interrompus

    Une connexion coupée reprend là où elle s'est arrêtée, sans renvoyer ce qui est déjà arrivé.

    Toutes les plateformes

  • Passer du relais au direct

    Un transfert commencé via le serveur relais passe sur un chemin direct dès qu'il s'en ouvre un.

    Toutes les plateformes

  • Application Windows

    Une application native pour Windows 11. Signée dès que les dons couvriront le certificat.

    Windows

  • Arch User Repository

    Installez et mettez à jour avec votre assistant AUR.

    Linux
Plus tard

2027

  • iPhone, iPad et Mac

    Des applications natives, dès que les dons couvriront le compte développeur Apple.

    iOS · macOS

  • Liens et livraison hors ligne

    Envoyer à quelqu'un qui n'est pas en ligne : une copie chiffrée attend jusqu'à 7 jours, et seul le lien l'ouvre.

    Toutes les plateformes

  • Un compte que le serveur ne conserve jamais

    Facultatif : ni e-mail, ni téléphone, ni mot de passe, ni numéro à saisir. Vos appareils détiennent le compte ; vos propres appareils s'envoient des fichiers, et vos contacts enregistrés vous en envoient, sans code.

    Toutes les plateformes

  • Contacts enregistrés

    Associez-vous une fois, vérifiez quatre mots, puis envoyez de nouveau à cette personne sans code.

    Toutes les plateformes

  • Mode confidentialité via Tor

    Le serveur relais joint via Tor, avec des tailles masquées par remplissage, pour que même nos serveurs ne voient pas votre adresse IP.

    Toutes les plateformes
Version 1.0

Après l'audit

  • Audit de sécurité indépendant

    Une société externe examine le protocole, la cryptographie et le code qui traite les données non fiables. Le rapport complet est publié.

    Toutes les plateformes

  • Un modèle formel de la poignée de main

    Une preuve ProVerif ou Tamarin que la poignée de main hybride tient ses promesses.

    Toutes les plateformes

  • Signatures post-quantiques

    Les clés des appareils ajoutent ML-DSA-65 à côté d'Ed25519, pour que même un futur ordinateur quantique ne puisse pas se faire passer pour vous.

    Toutes les plateformes

  • Relais communautaires

    Ceux qui le souhaitent peuvent utiliser des serveurs relais gérés par d'autres, à partir d'une liste signée.
