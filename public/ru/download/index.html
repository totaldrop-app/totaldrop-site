Что нового

Android 0.3.0-beta.7

  • Делитесь файлами с TotalDrop из любого приложения, например из Галереи или Файлов. Долгое нажатие на значок открывает «Отправить», «Получить» и «Отправить буфер обмена».
  • Отправьте текст: введите, поделитесь из другого приложения или выберите «Отправить через TotalDrop» для выделенного текста. Полученный текст показывается, не сохраняется, и его можно скопировать.
  • Заголовок над проверочными словами помещается на узких экранах.
  • Телефон больше не подключается к ретранслятору, которым не будет пользоваться другое устройство.

Linux 0.3.0-beta.6

  • Отправка текста: «Отправить текст» на экране отправки или «Отправить буфер обмена» в меню запуска приложения, которое открывает экран отправки с текстом из буфера обмена. Полученный текст показывается, а не сохраняется; скрытые символы показаны по имени, а «Копировать текст» копирует его в точности таким, каким он пришёл. В командной строке: totaldrop send --text "…" или totaldrop send - для текста со стандартного ввода.
  • Отправка из файлового менеджера: «Отправить через TotalDrop» в контекстном меню Dolphin, Nemo и Файлов (с nautilus-python). Правый щелчок по TotalDrop на панели задач или в меню запуска даёт «Отправка файлов», «Получение файлов» и «Отправить буфер обмена». Этих меню нет во Flatpak.
  • Flatpak: для x86-64 и ARM64; устанавливается, не затрагивая систему, в том числе там, где система только для чтения, и имеет доступ лишь к сети, ~/Downloads/TotalDrop, выбранным файлам и нескольким службам рабочего стола.
  • Ваш язык везде: центры приложений описывают TotalDrop на всех 35 языках приложения. С Qt 6.11 и новее контекстное меню текстовых полей на языке приложения. Настройки сообщают, что коды и проверочные слова остаются на английском.
  • Безопасность: отправляющее устройство больше не подключается к своему ретранслятору, если принимающее использует другой или никакого; этот ретранслятор больше не видит IP-адрес отправителя. Командная строка показывает управляющие символы в подробностях ошибки по имени, а не передаёт их терминалу (GHSA-c6jh-7p7q-8gg4).

Проверяйте, что устанавливаете

  • Скачивайте TotalDrop только из Google Play, с этой страницы или из выпусков проекта на GitHub. Больше мы нигде не публикуем.
  • В Linux установите скачанный файл командой sudo pacman -U, sudo apt install ./ или sudo dnf install ./ с его именем.
  • Flatpak устанавливается без sudo: flatpak install --user ./totaldrop-*.flatpak
  • Для каждого выпуска на GitHub указаны контрольные суммы SHA-256. Сверьте их, прежде чем запускать файл.
  • Всё собирается из открытого исходного кода, который вы можете прочитать и собрать сами.
