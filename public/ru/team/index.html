Как проверяется работа

  1. Повседневные изменения начинаются с открытой задачи и попадают в приложение только через pull request.

  2. Каждый pull request проходит автоматические проверки и проверку человеком или ИИ-агентом, который его не писал.

  3. Сливает, выпускает и развёртывает только руководитель проекта. Выпуски собираются в GitHub Actions, никогда на личном компьютере.
