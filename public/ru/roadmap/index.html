Что ждёт TotalDrop

Сроки — это цели, а не обещания: функция выходит, только когда она безопасна. Каждый шаг можно отслеживать в открытом репозитории.

Готово

Октябрь 2026

  • Открытый протокол

    TotalDrop Protocol v0: коды передачи на CPace, Noise XXpsk3 с постквантовым ML-KEM-768, QUIC с одноразовыми ключами. Описан, чтобы любой мог создать совместимое приложение.

    Все платформы

  • Клиент командной строки

    Отправка и получение из терминала в Linux, macOS и Windows.

    Linux · macOS · Windows

  • Бета для Android

    Отправка и получение по коду, на вашем языке, в цветах телефона. В Google Play по приглашениям.

    Android

  • Приложение для Linux

    Qt 6 и нативный Wayland. На лету следует теме KDE Plasma, Hyprland и Omarchy. Пакеты для Arch, Debian, Ubuntu и Fedora.

    Linux

  • Сквозь файрволы

    Оба устройства и слушают, и подключаются сами, поэтому файрвол на одной стороне больше не мешает передаче.

    Все платформы

  • Через интернет

    Устройства узнают свой публичный адрес через STUN и соединяются напрямую через большинство домашних роутеров. Когда это невозможно, зашифрованный трафик идёт через наш ретранслятор в Cloudflare, который не может его прочитать.

    Все платформы

  • Режим конфиденциальности в командной строке

    Только через ретранслятор: другая сторона никогда не узнает ваш IP-адрес.

    Linux · macOS · Windows

  • Режим конфиденциальности в приложениях

    Один переключатель в настройках: всё идёт через ретранслятор, поэтому другое устройство никогда не узнает ваш IP-адрес.

    Android · Linux

  • Linux на ARM

    Пакеты .deb и .rpm для компьютеров на ARM64, таких как Snapdragon X и NVIDIA RTX Spark.

    Linux

  • На вашем языке

    Приложения и этот сайт на 35 языках, с числовыми форматами вашего региона. Носители языка проверяют черновики.

    Все платформы

  • Аккаунт, который сервер никогда не хранит

    Необязательно: без почты, телефона, пароля и номера для ввода. Аккаунт хранят ваши устройства; ваши устройства отправляют файлы друг другу, а сохранённые контакты — вам, без кода.
