Verstuur een bestand rechtstreeks naar een ander apparaat.

TotalDrop brengt bestanden rechtstreeks van jouw apparaat naar dat van de ander, end-to-end versleuteld. Je deelt een korte code; niemand onderweg kan lezen wat je verstuurt. Geen account, geen e-mail, geen telefoonnummer.

Waarom TotalDrop

  • Er wordt niets geüpload

    Bestanden gaan van jouw apparaat naar dat van de ander. Er wacht geen kopie op de server van een bedrijf, en geen link verloopt na een week.

  • Nooit een account

    Geen e-mail, geen telefoonnummer, geen registratie. Een korte code is alles wat twee apparaten nodig hebben.

  • Elk platform, één app

    Vandaag Android, Linux en de opdrachtregel; Windows, macOS en iOS zijn onderweg. Van telefoon naar laptop, van elk merk naar elk merk.

  • Geen groottelimiet van ons

    Hele mappen, lange video's, foto's in originele kwaliteit. Alleen je schijf en je verbinding bepalen de grens.

  • Gecontroleerd, niet vertrouwd

    Vier woorden op beide schermen bewijzen dat niemand ertussen zit. De versleuteling is end-to-end en post-kwantum.

  • Vrij en open, voorgoed

    Open source onder de GPL, betaald met donaties. Geen advertenties, geen tracking, geen premiumversie.

Drie stappen

  1. Kies bestanden

    Elk type, zoveel als je wilt. De ontvanger krijgt alleen wat jij hebt gekozen.

  2. Deel de code

    Een getal en twee woorden, zoals 7-harbor-rocket. Hij werkt één keer en verloopt daarna.

  3. Vergelijk vier woorden

    Beide schermen tonen dezelfde vier woorden. Als ze overeenkomen, is de verbinding alleen van jullie.

Via het internet verbinden de twee apparaten waar mogelijk rechtstreeks. Als een router of firewall in de weg zit, gaat de versleutelde overdracht via onze relayserver, die haar niet kan lezen.

Alleen jij en de ontvanger kunnen het openen

Versleuteld voordat het vertrekt
Bestanden worden op je apparaat versleuteld en alleen op dat van de ontvanger ontsleuteld. De sleutels bestaan nergens anders.
De code is niet offline te raden
De code wordt via een PAKE-handshake een sleutel, zodat een verkeerde gok meteen mislukt en de poging verbruikt is. De sleuteluitwisseling bevat post-kwantum ML-KEM.
Onze server stelt alleen voor
Hij ziet je IP-adres en het getal van de code, nooit de woorden, de bestandsnamen of de bestanden. Hij houdt geen logboeken bij.
Code die iedereen kan controleren
Elke regel is openbaar. Versie 1.0 verschijnt pas na een onafhankelijke beveiligingsaudit.
