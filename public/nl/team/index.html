Hoe het werk wordt gecontroleerd

  1. Dagelijkse wijzigingen beginnen als een openbare issue en komen alleen via een pull request in de app.

  2. Elk pull request doorloopt de automatische controles en een review door een persoon of een AI-agent die het niet heeft geschreven.

  3. Alleen de projectleider voegt samen, brengt uit en rolt uit. Releases worden gebouwd door GitHub Actions, nooit op een eigen computer.
