O que vem por aí no TotalDrop

As datas são metas, não promessas: um recurso só é lançado quando é seguro. Cada passo pode ser acompanhado no repositório aberto.

Pronto

Outubro de 2026

  • Um protocolo aberto

    TotalDrop Protocol v0: códigos de transferência com CPace, Noise XXpsk3 com ML-KEM-768 pós-quântico, QUIC com chaves de uso único. Documentado para que qualquer pessoa possa criar um app compatível.

    Todas as plataformas

  • Cliente de linha de comando

    Envie e receba pelo terminal no Linux, macOS e Windows.

    Linux · macOS · Windows

  • Beta para Android

    Envie e receba com um código, no seu idioma, com as cores do celular. No Google Play por convite.

    Android

  • App para Linux

    Qt 6 e Wayland nativo. Acompanha ao vivo o tema do KDE Plasma, Hyprland e Omarchy. Pacotes para Arch, Debian, Ubuntu e Fedora.

    Linux

  • Através de firewalls

    Os dois dispositivos escutam e chamam, então um firewall de um lado não impede mais a transferência.

    Todas as plataformas

  • Pela internet

    Os dispositivos descobrem seu endereço público com STUN e se conectam diretamente através da maioria dos roteadores domésticos. Quando isso é impossível, o tráfego criptografado passa pelo nosso servidor de retransmissão na Cloudflare, que não consegue lê-lo.

    Todas as plataformas

  • Modo de privacidade na linha de comando

    Só retransmissão: o outro lado nunca descobre seu endereço IP.

    Linux · macOS · Windows

  • Modo de privacidade nos apps

    Uma chave nas Configurações: tudo passa pelo servidor de retransmissão, então o outro dispositivo nunca descobre seu endereço IP.

    Android · Linux

  • Linux em ARM

    Pacotes .deb e .rpm para computadores ARM64 como Snapdragon X e NVIDIA RTX Spark.

    Linux

  • No seu idioma

    Os apps e este site em 35 idiomas, com os formatos numéricos da sua região. Falantes nativos estão conferindo os rascunhos.

    Todas as plataformas

Depois

2027

  • iPhone, iPad e Mac

    Apps nativos, quando as doações cobrirem a conta de desenvolvedor da Apple.

    iOS · macOS

  • Links e entrega off-line

    Envie para alguém que não está on-line: uma cópia criptografada espera até 7 dias, e só o link a abre.

    Todas as plataformas

  • Uma conta que o servidor nunca guarda

    Opcional: sem e-mail, telefone, senha ou número para digitar. Seus dispositivos guardam a conta; seus próprios dispositivos enviam arquivos entre si, e contatos salvos enviam para você, sem código.

    Todas as plataformas

  • Contatos salvos

    Pareie uma vez, confira quatro palavras e envie para essa pessoa de novo sem código.

    Todas as plataformas

  • Modo de privacidade pelo Tor

    O servidor de retransmissão acessado pelo Tor, com tamanhos preenchidos, para que nem nossos servidores vejam seu endereço IP.

    Todas as plataformas

Depois da auditoria

  • Auditoria de segurança independente

    Uma empresa externa analisa o protocolo, a criptografia e o código que lida com dados não confiáveis. O relatório completo é publicado.

    Todas as plataformas

  • Um modelo formal do handshake

    Uma prova com ProVerif ou Tamarin de que o handshake híbrido cumpre o que promete.

    Todas as plataformas

  • Assinaturas pós-quânticas

    As chaves dos dispositivos ganham ML-DSA-65 ao lado do Ed25519, para que nem um futuro computador quântico consiga se passar por você.

    Todas as plataformas

  • Retransmissão da comunidade

    Quem quiser poderá usar servidores de retransmissão mantidos por outras pessoas, a partir de uma lista assinada.

    Todas as plataformas
