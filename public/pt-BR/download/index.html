    Beta

    Feito com Qt 6 para Wayland. Usa as cores, as fontes e os ícones do seu desktop: Plasma, Hyprland, Omarchy, GNOME.

    • Um pacote separado para cada família de distribuições: todos para x86-64; Debian, Ubuntu e Fedora também para ARM64

Novidades

Android 0.3.0-beta.7

  • Compartilhe arquivos com o TotalDrop a partir de qualquer app, como Galeria ou Arquivos. Ao tocar e segurar o ícone, aparecem Enviar, Receber e Enviar área de transferência.
  • Envie um texto: digite, compartilhe de outro app ou escolha "Enviar com o TotalDrop" no texto selecionado. O texto recebido é mostrado, não salvo, e pode ser copiado.
  • O título acima das palavras de verificação cabe em telas estreitas.
  • Seu celular não se conecta mais a um servidor de retransmissão que o outro dispositivo não vai usar.

Linux 0.3.0-beta.6

  • Enviar texto: "Enviar texto" na tela de envio, ou "Enviar área de transferência" no menu do lançador do app, que abre a tela de envio com o texto da área de transferência. Um texto recebido é mostrado, não salvo; caracteres ocultos aparecem pelo nome, e "Copiar texto" copia exatamente como chegou. Na linha de comando: totaldrop send --text "…", ou totaldrop send - para o texto da entrada padrão.
  • Enviar pelo gerenciador de arquivos: "Enviar com o TotalDrop" no menu de contexto do Dolphin, Nemo e Arquivos (com nautilus-python). Clicar com o botão direito no TotalDrop na barra de tarefas ou no lançador oferece "Enviar arquivos", "Receber arquivos" e "Enviar área de transferência". Esses menus não estão no Flatpak.
  • Flatpak: para x86-64 e ARM64; instala sem mexer no sistema, mesmo em sistemas somente leitura, e acessa só a rede, ~/Downloads/TotalDrop, os arquivos escolhidos e alguns serviços da área de trabalho.
  • Seu idioma, em todo lugar: as centrais de software descrevem o TotalDrop nos 35 idiomas do app. Com Qt 6.11 ou mais recente, o menu de contexto dos campos de texto fica no idioma do app. As configurações dizem que códigos e palavras de verificação continuam em inglês.
  • Segurança: um dispositivo que envia não se conecta mais ao seu relay quando o que recebe usa outro ou nenhum; esse relay não vê mais o endereço IP de quem envia. A linha de comando nomeia os caracteres de controle nos detalhes de erro em vez de passá-los ao terminal (GHSA-c6jh-7p7q-8gg4).

Confira o que você instala

  • Baixe o TotalDrop só pelo Google Play, por esta página ou pelas versões do projeto no GitHub. Não publicamos em nenhum outro lugar.
  • No Linux, instale o arquivo baixado com sudo pacman -U, sudo apt install ./ ou sudo dnf install ./ seguido do nome dele.
  • Um Flatpak é instalado sem sudo: flatpak install --user ./totaldrop-*.flatpak
  • Cada versão no GitHub lista somas de verificação SHA-256. Compare-as antes de executar um arquivo.
  • Tudo é compilado a partir do código-fonte público, que você pode ler e compilar por conta própria.

O TotalDrop é de código aberto e desenvolvido de forma aberta.
