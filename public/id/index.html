Kirim file dan teks langsung ke perangkat lain.

TotalDrop memindahkan file, seluruh folder, dan teks papan klip langsung dari perangkat Anda ke perangkat penerima, terenkripsi end-to-end dengan kunci pascakuantum. Bagikan kode singkat; tidak seorang pun di tengah jalan dapat membaca apa yang Anda kirim. Tanpa akun, tanpa email, tanpa nomor telepon.

Mengapa TotalDrop

  • Tidak ada yang diunggah

    File berpindah dari perangkat Anda ke perangkat penerima. Tidak ada salinan yang menunggu di server perusahaan, dan tidak ada tautan yang kedaluwarsa dalam seminggu.

  • Tanpa akun, selamanya

    Tanpa email, tanpa nomor telepon, tanpa pendaftaran. Dua perangkat hanya butuh kode singkat.

  • Setiap platform, satu aplikasi

    Android, Linux, dan baris perintah hari ini; Windows, macOS, dan iOS segera hadir. Dari ponsel ke laptop, dari merek apa pun ke merek apa pun.

  • File, folder, dan teks papan klip

    Kirim foto kualitas asli, folder berukuran besar, atau catatan yang disalin. Teks tiba siap disalin dengan karakter tersembunyi yang dinamai, tanpa pernah ditulis ke disk.

  • Diverifikasi, bukan dipercaya

    Empat kata di kedua layar membuktikan tidak ada orang di tengah. Enkripsinya end-to-end dan pascakuantum.

  • Gratis dan terbuka, selamanya

    Open source di bawah GPL, dibiayai oleh donasi. Tanpa iklan, tanpa pelacakan, tanpa paket premium.

Tiga langkah

  1. Pilih file atau teks

    Pilih file, seluruh folder, atau teks papan klip—atau kirim langsung dari menu bagikan sistem atau pengelola file Anda.

  2. Bagikan kode

    Sebuah angka dan dua kata, seperti 7-harbor-rocket. Kode hanya berfungsi sekali, lalu kedaluwarsa.

  3. Bandingkan empat kata

    Kedua layar menampilkan empat kata yang sama. Jika cocok, koneksi itu hanya milik Anda.

Melalui internet, kedua perangkat terhubung langsung di mana pun memungkinkan. Jika router atau firewall menghalangi, transfer terenkripsi melewati server relai kami, yang tidak dapat membacanya.

Hanya Anda dan penerima yang dapat membukanya

Terenkripsi sebelum keluar
File dienkripsi di perangkat Anda dan hanya didekripsi di perangkat penerima. Kuncinya tidak pernah ada di tempat lain.
Handshake PAKE pascakuantum
Kode menggerakkan jabat tangan CPace yang memasok kunci bagi Noise XXpsk3 dengan kunci hibrida X25519 dan ML-KEM-768. Tebakan salah langsung gagal dan menghanguskan percobaan.
Server kami hanya memperkenalkan
Server melihat alamat IP Anda dan angka pada kode, tidak pernah kata-katanya, nama file, atau filenya. Saat Mode Privasi aktif, perangkat lawan pun tidak pernah mengetahui alamat IP Anda.
Dibuktikan dengan Tamarin, diaudit sebelum 1.0
Enam model simbolis, 61 lema terperiksa mesin, dan 27 mutan regresi memverifikasi calon akun Ghost Ring yang tak terlihat server di pembukti Tamarin. Versi 1.0 menunggu audit independen.
