Kirim file langsung ke perangkat lain.

TotalDrop memindahkan file langsung dari perangkat Anda ke perangkat penerima, terenkripsi end-to-end. Anda membagikan kode singkat; tidak ada seorang pun di tengah jalan yang dapat membaca apa yang Anda kirim. Tanpa akun, email, atau nomor telepon.

Mengapa TotalDrop

  • Tidak ada yang diunggah

    File berpindah dari perangkat Anda ke perangkat penerima. Tidak ada salinan yang menunggu di server perusahaan, dan tidak ada tautan yang kedaluwarsa dalam seminggu.

  • Tanpa akun, selamanya

    Tanpa email, tanpa nomor telepon, tanpa pendaftaran. Dua perangkat hanya butuh kode singkat.

  • Setiap platform, satu aplikasi

    Android, Linux, dan baris perintah hari ini; Windows, macOS, dan iOS segera hadir. Dari ponsel ke laptop, dari merek apa pun ke merek apa pun.

  • Tanpa batas ukuran dari kami

    Seluruh folder, video panjang, foto kualitas asli. Hanya disk dan koneksi Anda yang menentukan batasnya.

  • Diverifikasi, bukan dipercaya

    Empat kata di kedua layar membuktikan tidak ada orang di tengah. Enkripsinya end-to-end dan pascakuantum.

  • Gratis dan terbuka, selamanya

    Open source di bawah GPL, dibiayai oleh donasi. Tanpa iklan, tanpa pelacakan, tanpa paket premium.

Tiga langkah

  1. Pilih file

    Jenis apa pun, sebanyak yang Anda mau. Penerima hanya mendapat apa yang Anda pilih.

  2. Bagikan kode

    Sebuah angka dan dua kata, seperti 7-harbor-rocket. Kode hanya berfungsi sekali, lalu kedaluwarsa.

  3. Bandingkan empat kata

    Kedua layar menampilkan empat kata yang sama. Jika cocok, koneksi itu hanya milik Anda.

Melalui internet, kedua perangkat terhubung langsung di mana pun memungkinkan. Jika router atau firewall menghalangi, transfer terenkripsi melewati server relai kami, yang tidak dapat membacanya.

Hanya Anda dan penerima yang dapat membukanya

Terenkripsi sebelum keluar
File dienkripsi di perangkat Anda dan hanya didekripsi di perangkat penerima. Kuncinya tidak pernah ada di tempat lain.
Kode tidak dapat ditebak secara offline
Kode diubah menjadi kunci melalui handshake PAKE, sehingga tebakan yang salah langsung gagal dan percobaan itu hangus. Pertukaran kunci menyertakan ML-KEM pascakuantum.
Server kami hanya memperkenalkan
Server melihat alamat IP Anda dan angka pada kode, tidak pernah kata-katanya, nama file, atau filenya. Server tidak menyimpan log.
Kode yang dapat diperiksa siapa pun
Setiap baris bersifat publik. Versi 1.0 baru dirilis setelah audit keamanan independen.
