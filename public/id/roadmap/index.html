Mengapa TotalDrop Cara kerja Keamanan Unduh

Terjemahan ini masih draf dan sedang ditinjau.

Peta jalan · diperbarui 30 Oktober 2026

Yang akan datang di TotalDrop

Tanggal adalah target, bukan janji: fitur hanya dirilis saat sudah aman. Setiap langkah dapat diikuti di repositori terbuka.

Selesai

Oktober 2026

  • Protokol terbuka

    TotalDrop Protocol v0: kode transfer dengan CPace, Noise XXpsk3 dengan ML-KEM-768 pascakuantum, QUIC dengan kunci sekali pakai. Ditulis agar siapa pun dapat membuat aplikasi yang kompatibel.

    Semua platform

  • Klien baris perintah

    Kirim dan terima dari terminal di Linux, macOS, dan Windows.

    Linux · macOS · Windows

  • Android beta

    Kirim dan terima dengan kode, dalam bahasa Anda, mengikuti warna ponsel. Di Google Play dengan undangan.

    Android

  • Aplikasi Linux

    Qt 6 dan Wayland native. Mengikuti tema KDE Plasma, Hyprland, dan Omarchy secara langsung. Paket untuk Arch, Debian, Ubuntu, dan Fedora.

    Linux

  • Menembus firewall

    Kedua perangkat mendengarkan dan menghubungi, jadi firewall di satu sisi tidak lagi menghentikan transfer.

    Semua platform

  • Melalui internet

    Perangkat menemukan alamat publiknya dengan STUN dan terhubung langsung melalui sebagian besar router rumah. Jika tidak memungkinkan, lalu lintas terenkripsi melewati server relai kami di Cloudflare, yang tidak dapat membacanya.

    Semua platform

  • Mode privasi di baris perintah

    Hanya relai: pihak lain tidak pernah mengetahui alamat IP Anda.

    Linux · macOS · Windows

  • Mode privasi di aplikasi

    Satu sakelar di Setelan: semuanya melewati server relai, jadi perangkat lain tidak pernah mengetahui alamat IP Anda.

    Android · Linux

  • Linux di ARM

    Paket .deb dan .rpm untuk komputer ARM64 seperti Snapdragon X dan NVIDIA RTX Spark.

    Linux

  • Dalam bahasa Anda

    Aplikasi dan situs ini dalam 35 bahasa, dengan format angka wilayah Anda. Penutur asli sedang memeriksa drafnya.

    Semua platform
Sekarang

November 2026

  • Pindai kode QR dengan kamera

    Arahkan ponsel ke layar pengirim alih-alih mengetik kode.

    Android

  • Terima di browser

    Buka tautan, ketik kode, simpan file. Tanpa instalasi, tetap terenkripsi end-to-end.

    Web
Berikutnya

Akhir 2026 – awal 2027

  • Lanjutkan transfer yang terputus

    Koneksi yang terputus dilanjutkan dari titik terakhir, tanpa mengirim ulang yang sudah tiba.

    Semua platform

  • Beralih dari relai ke langsung

    Transfer yang dimulai melalui relai pindah ke jalur langsung begitu jalur itu terbuka.

    Semua platform

  • Aplikasi Windows

    Aplikasi native untuk Windows 11. Ditandatangani setelah donasi mencukupi sertifikatnya.

    Windows

  • Arch User Repository

    Instal dan perbarui dengan AUR helper Anda.

    Linux
Nanti

2027

  • iPhone, iPad, dan Mac

    Aplikasi native, setelah donasi mencukupi akun developer Apple.

    iOS · macOS

  • Tautan dan pengiriman offline

    Kirim ke seseorang yang sedang offline: salinan terenkripsi menunggu hingga 7 hari, dan hanya tautannya yang dapat membukanya.

    Semua platform

  • Akun yang tidak pernah disimpan server

    Opsional: tanpa email, telepon, kata sandi, atau nomor untuk diketik. Perangkat Anda yang menyimpan akun; perangkat Anda saling mengirim, dan kontak tersimpan mengirim ke Anda, tanpa kode.

    Semua platform

  • Kontak tersimpan

    Pasangkan sekali, periksa empat kata, lalu kirim lagi ke orang itu tanpa kode.

    Semua platform

  • Mode privasi melalui Tor

    Server relai dijangkau melalui Tor, dengan ukuran yang disamarkan, sehingga server kami pun tidak melihat alamat IP Anda.

    Semua platform
Versi 1.0

Setelah audit

  • Audit keamanan independen

    Firma luar meninjau protokol, kriptografi, dan kode yang menangani input tak tepercaya. Laporan lengkapnya dipublikasikan.

    Semua platform

  • Model formal handshake

    Bukti dengan ProVerif atau Tamarin bahwa handshake hibrida menepati janjinya.

    Semua platform

  • Tanda tangan pascakuantum

    Kunci perangkat menambahkan ML-DSA-65 di samping Ed25519, sehingga komputer kuantum di masa depan pun tidak dapat menyamar sebagai Anda.

    Semua platform

  • Server relai komunitas

    Mereka yang memilih ikut dapat menggunakan server relai yang dijalankan orang lain, dari daftar yang ditandatangani.

    Semua platform
