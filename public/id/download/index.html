Unduh TotalDrop

Gratis, open source, tanpa akun. Pilih perangkat Anda; perangkat yang sedang Anda gunakan sudah ditandai.

    Tersedia

  • Untuk perangkat ini

    Aplikasi Linux

    Beta

    Dibuat dengan Qt 6 untuk Wayland. Mengambil warna, font, dan ikon dari desktop Anda: Plasma, Hyprland, Omarchy, GNOME.

    • Paket terpisah untuk setiap keluarga distribusi: semuanya untuk x86-64; Debian, Ubuntu, dan Fedora juga untuk ARM64
    • Paket .pkg, .deb, dan .rpm juga memasang perintah totaldrop dan menu klik kanan untuk Dolphin, Files, dan Nemo
    • Gunakan satu paket Linux dalam satu waktu. Flatpak dan paket .pkg, .deb, atau .rpm memakai nama yang sama, jadi saat salah satunya terbuka, menjalankan yang lain akan memunculkan jendela yang terbuka alih-alih membuka jendela kedua.
    Arch, Omarchy, Manjaro Debian, Ubuntu (.deb) Fedora (.rpm) Flatpak

    Tombol di atas untuk x86-64. Untuk ARM64: Debian, Ubuntu (.deb, ARM64) · Fedora (.rpm, ARM64) · Flatpak (ARM64)

Yang baru

Android 0.3.0-beta.7

  • Bagikan file ke TotalDrop dari aplikasi apa pun, seperti Galeri atau File. Tekan lama ikon aplikasi untuk Kirim, Terima, dan Kirim papan klip.
  • Kirim teks: ketik, bagikan dari aplikasi lain, atau pilih "Kirim dengan TotalDrop" pada teks yang dipilih. Teks yang tiba ditampilkan, tidak disimpan, dan dapat disalin.
  • Judul di atas kata verifikasi muat di layar sempit.
  • Ponsel Anda tidak lagi terhubung ke server relai yang tidak akan dipakai perangkat lain.

Linux 0.3.0-beta.6

  • Kirim teks: "Kirim teks" di layar kirim, atau "Kirim papan klip" di menu peluncur aplikasi, yang membuka layar kirim dengan teks dari papan klip. Teks yang masuk ditampilkan, tidak disimpan; karakter tersembunyi ditampilkan dengan namanya, dan "Salin teks" menyalinnya persis seperti saat datang. Di baris perintah: totaldrop send --text "…", atau totaldrop send - untuk teks dari masukan standar.
  • Kirim dari pengelola file: "Kirim dengan TotalDrop" di menu klik kanan Dolphin, Nemo, dan Files (dengan nautilus-python). Klik kanan TotalDrop di bilah tugas atau peluncur memberi "Kirim file", "Terima file", dan "Kirim papan klip". Menu ini tidak ada di Flatpak.
  • Flatpak: untuk x86-64 dan ARM64; terpasang tanpa mengubah sistem, juga di sistem hanya-baca, dan hanya menjangkau jaringan, ~/Downloads/TotalDrop, file yang Anda pilih, dan beberapa layanan desktop.
  • Bahasa Anda di mana-mana: pusat perangkat lunak menjelaskan TotalDrop dalam ke-35 bahasa aplikasi. Dengan Qt 6.11 atau lebih baru, menu klik kanan kolom teks memakai bahasa aplikasi. Pengaturan menyebutkan bahwa kode dan kata verifikasi tetap berbahasa Inggris.
  • Keamanan: perangkat pengirim tidak lagi terhubung ke relay-nya bila perangkat penerima memakai relay lain atau tidak sama sekali; relay itu tidak lagi melihat alamat IP pengirim. Baris perintah menampilkan karakter kontrol dalam detail galat dengan namanya alih-alih meneruskannya ke terminal (GHSA-c6jh-7p7q-8gg4).

Periksa apa yang Anda instal

  • Dapatkan TotalDrop hanya dari Google Play, dari halaman ini, atau dari rilis GitHub proyek. Kami tidak menerbitkannya di tempat lain.
  • Di Linux, instal file yang Anda unduh dengan sudo pacman -U, sudo apt install ./ atau sudo dnf install ./ diikuti namanya.
  • Flatpak dipasang tanpa sudo: flatpak install --user ./totaldrop-*.flatpak
  • Setiap rilis di GitHub mencantumkan checksum SHA-256. Bandingkan sebelum Anda menjalankan file.
  • Semuanya dibuat dari kode sumber publik, yang dapat Anda baca dan build sendiri.

TotalDrop adalah open source dan dikembangkan secara terbuka.
