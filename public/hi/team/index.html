काम की जाँच कैसे होती है

  1. रोज़मर्रा के बदलाव एक सार्वजनिक issue से शुरू होते हैं और केवल pull request के ज़रिए ऐप तक पहुँचते हैं।

  2. हर pull request स्वचालित जाँचों से और ऐसे व्यक्ति या AI एजेंट की समीक्षा से गुज़रता है जिसने उसे नहीं लिखा।

  3. केवल परियोजना प्रमुख विलय, रिलीज़ और परिनियोजन करता है। रिलीज़ GitHub Actions में बनती हैं, कभी निजी कंप्यूटर पर नहीं।
